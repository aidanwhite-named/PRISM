PRISM for Windows x64

Run PRISM.exe. The application opens in your default browser.
Keep the console running. Stop with Ctrl+C or PRISM.exe --stop.
Closing a browser tab does not stop PRISM.
Running PRISM.exe again opens the existing instance.

Python is included. Install and log in to one supported AI CLI separately:
Claude Code, Codex CLI, or agy. Configure it in Settings.
Node.js is needed only if your chosen CLI requires it.

Data: %LOCALAPPDATA%\PRISM
Editable prompts: %LOCALAPPDATA%\PRISM\prompts
Uninstalling or updating the application preserves your data.
Optional semantic-search models are not included.

Options: --port 9000, --no-browser, --stop
PRISM_DATA_DIR and PRISM_PROMPT_DIR override the storage locations.

Portable distribution: extract the ENTIRE folder; do not move PRISM.exe alone.
This build is unsigned. Project licensing must be settled before public distribution.
