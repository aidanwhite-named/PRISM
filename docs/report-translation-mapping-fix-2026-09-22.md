# 번역·발췌 순서와 종속항 분석 비활성화 수정

대상 실행: `4b25fa24-69d7-4690-8b7c-d8e5a2910671` (2026-09-22).

## 확인한 원인

실제 최종 입력에는 외국어 문헌의 한국어 번역 우선 규칙이 들어 있었다.
그러나 출력 형식의 대표 발췌 항목은 번역과 원문의 배치를 다시 명시하지 않았다.
생성 결과 A·B에서는 번역과 영문 사이에 대응 해설이 끼었고, C에서는 영문 뒤에
한국어 뜻을 설명했다. 60자 제한을 넘는 영문도 있었다. 저장 결과와 원시 응답에서
확인되는 모델 출력의 형식 미준수이며, 화면에서 순서를 바꾼 문제가 아니다.
이 프롬프트의 모호함이 미준수의 유일한 원인이라고 확정할 수는 없다.

종속항 버튼은 검증된 `citation_mapping.items`가 없으면 비활성화된다.
원시 응답에는 매핑 여는 표식과 완전한 4개 항목 JSON이 있었으나 닫는 표식이 없었다.
기존 정규식은 여는 표식과 닫는 표식을 모두 요구해 이를 블록 누락으로 처리했다.
표 복구 경로도 불완전한 프로토콜 블록이 있으면 거절하므로 버튼이 잠겼다.

## 수정

- 마스터 프롬프트의 실제 출력 양식과 최종 점검을
  `“한국어 번역문” (“외국어 원문 구절”, 위치)` 다음에 대응 설명을 쓰도록 통일했다.
  번역은 근거 문장을 충실히 옮기고 병기 원문은 그 문장 안의 60자 이하 연속 구절이다.
- 매핑 JSON이 완전하고 마지막에 있으며 닫는 표식만 누락된 경우 기존 항목 검증을
  그대로 거쳐 읽는다. 잘린 JSON, 중복 블록, 없는 자료 번호, 모호한 후속 내용은 거절한다.
- 기존 성공 보고서도 조회 시 복구한다. `final_prompt.txt`의 자료 번호와 첨부 ID를
  대조하므로 DB 첨부 나열 순서에 의존하지 않는다. 입력 파일이 없으면 추정하지 않는다.
- 복구한 기계용 JSON은 화면·복사·다운로드에 사용하는 API 보고서 본문에서 제거한다.
  저장된 원시 응답과 기존 보고서 파일은 변경하지 않는다.
- 매핑 출력 지침에 종료 표식까지 출력하도록 명시했다.

## 검증과 적용

관련 백엔드 테스트 61개, RunPage 화면 테스트 10개 통과. 새 실행의 매핑 처리,
기존 이력 조회, 번호 순서를 유지하는 종속항 후속 실행과 오류 거부를 검증했다.
실제 대상 보고서에서도 4개 문헌 연결이 복구되고 매핑 JSON이 표시 본문에서 제거됨을
읽기 전용으로 확인했다. 실제 모델로 새 보고서를 생성해 번역 배치를 재평가하지는 않았다.

현재 실행 중인 서버에는 재시작이 필요하다. 서버 종료·재시작 명령은 자동 승인 검토가
정책상 차단하여 실행되지 않았다. 프로그램을 다시 실행한 뒤 기존 보고서를 열면
매핑 복구가 적용된다. 번역 출력 양식은 새로 생성하는 보고서부터 적용된다.
