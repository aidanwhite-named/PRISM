# 원문 발췌·분류 표시·입력 문헌 중복 수정

## 변경 동작

- 원문을 바꿔 쓰거나 생략 부호로 합친 발췌는 계속 거부한다. `source_fetch`가 이미 읽은 구간의 선택 식별자를 제공하고, `save_findings`가 선택한 원문을 그대로 저장한다. 문헌 일치, 실제 읽은 범위, 번역 및 대응 설명 검증은 유지한다.
- 실패한 발췌별로 실제 원문 교정 선택지를 반환한다. 같은 호출 안에서 고칠 수 있으며, 종료 시 남아 있다면 기존 검증 시간 안에서 교정을 한 번만 추가 시도한다. 교정 단계의 MCP 신규 검색·원문 조회를 차단하고 이미 읽은 원문을 재사용한다. 교정 입력에 명세서를 다시 전송하지 않는다.
- 요약과 X/Y/Z 개수는 저장된 검증 상태로 계산한다. AI 최종 설명은 별도의 감사 기록으로 보존한다. 검증 미완료 결과를 완료로 표시하지 않으며, 카드와 보고서에는 같은 최신 판단과 차이를 한 번씩 표시한다.
- 입력 PDF의 첫 페이지 서지정보에서 DOI와 제목을 식별한다. 정확히 같은 문헌은 결과·후보에서 제외하고 알려진 DOI/URL 조회를 네트워크 요청 전에 생략한다. 검색 응답에서 확인한 같은 문헌의 다른 URL도 이후 조회에서 제외한다. 참고문헌 전체를 제외하지 않으며 인용 문헌 탐색은 허용한다.
- 여러 입력 문헌과 이어서 검색할 때도 식별정보·제외 기록을 유지한다. 공개일 저장은 이번 변경 대상이 아니다.
