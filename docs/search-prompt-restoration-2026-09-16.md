# 기본 검색 프롬프트 복원 (2026-09-16)

사용자가 제시한 검색 프롬프트를 기본 본문에 그대로 복원했다. 전략 등록·선택 기능은 유지한다.
시스템에 중복되어 있던 출처 우선순위, 관계별 질의 강제, 첫 페이지 보완과 반복 탐색 지시를 제거했다.
A/B/C 정의는 기본 본문에 한 번만 전달하고, 명세서 참고 안내는 청구항에 없는 한정을 추가하지 않는 규칙으로 줄였다.

도구 접근 경계, 응답 근거 참조, JSON 출력 형식은 유지한다. 원문 미확인 참고 후보는 group:null과 사유로 남기도록 안내한다.
기준일을 비워 두면 날짜 제한이 없고, 사용자가 별도로 기준일을 입력하면 기존 공개일 제한을 적용한다.
기존 작업 스냅샷과 사용자 정의 전략은 바꾸지 않는다. 시스템 지시 변경은 백엔드 재시작 후 적용된다.

자동 검증은 프롬프트 조립, 검색 API, 근거 확인, Provider별 도구 안내 및 날짜 처리 테스트로 수행한다.
실제 외부 검색 결과의 품질 비교는 수행하지 않았다.
