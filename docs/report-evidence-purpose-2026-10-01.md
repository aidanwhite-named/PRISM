# 구성 대응 판단과 인용 용도 분리

기존 경고는 원문 발췌를 모두 긍정 대응으로 해석하는 검사와 모델의 독립적인 문헌 역할 선언이 충돌하면서 발생했다. 최신 실행의 4개 PDF, 총 61페이지가 입력에 있었으며 ATT-03의 인용은 실제 처리 방식과 청구항의 차이를 설명하는 용도였다. D의 ATT-04는 역할만 긍정으로 선언하고 설명·발췌에 연결하지 않았다.

## 변경

- 새 생성 규격은 V5이다. 각 구성의 `evidence_uses`에 발췌별 `support`/`contrast`를 지정하고 모든 발췌를 설명의 근거 ID와 연결한다.
- 긍정 문헌 역할은 실제 support 연결에서 산출한다. 비교 인용만 사용하는 문헌은 comparison으로 산출하며 문헌 전체 미발견을 추정하지 않는다. 명시적 `not_found`와 비교 인용은 공존할 수 있다.
- 비교 인용만으로 주 문헌의 양수 유사도를 뒷받침할 수 없다. 실제 긍정 근거 누락, 잘못된 원문·번역·문헌 연결, unavailable 문헌의 발췌 연결은 계속 점검한다.
- 구성 교정에는 관련 문헌의 원래 전달 원문과 문장 번호를 다시 제공한다. 검색 전달에서는 검색 구간만 제공하며 검토 범위를 넓히지 않는다. 새 발췌는 제공 문장 번호에서만 선택하고 연결·연속성·문헌·번역 범위를 검증한다. 검토 원문을 제공하지 않은 문헌에 새 미발견 판단을 만들 수 없다.
- 기존 원문·번역·문헌 매핑은 보존한다. 분할 복구 시에도 구성별 발췌 용도를 모든 분할 ID에 전달한다. V1–V4의 기존 해석은 유지한다.

## 최신 보고서 재검토

대상 작업: `67da954c-adfa-4b30-bc22-084941ff903b`.

자동 재검토의 입력·응답·채택/거절 기록을 보존했다. 첫 응답은 평문 근거 ID와 잘못된 unavailable 표시로 거절됐고, 다음 응답은 B만 반환했다. D에 대한 후속 응답도 보존했다. 이 기록과 검증된 원문을 확인한 뒤, 별도의 agent_review 기록으로 B/D의 최소 근거와 용도를 정리했다. 자동 교정이 모두 성공한 것으로 기록하지 않았다.

ATT-04의 단락 0012–0013에는 LED별 상태를 이진 형태로 복원해 타임스탬프를 계산하고, 서로 다른 위치의 두 LED 시계 시각을 비교해 롤링 셔터 값을 정하는 처리가 있다. 이 연속 두 문장을 E15로 등록해 LED 상태 이용·지연값 산출의 부분 대응을 설명했다. 청구항의 이미지 센서 오프셋과 같은 관계인지 확인이 필요한 부분은 차이점 한 줄에 남겼다. B는 E3/E8/E10, D는 E5/E14/E13/E15를 연결하며 배경·중복 설명을 줄였다.

기존 점검 3개 → 0개. B의 표시 근거 5개 → 3개, D의 유효 연결 근거 6개 → 4개. 기존 모든 근거 원문·번역과 문헌 매핑·점수, A/C 분석을 보존했다. 원 응답은 수정하지 않았으며 저장 보고서·분석 데이터는 최초 원본 백업 후 함께 갱신했다.

재현·교정 자료: `artifacts/report-evidence-purpose-20261001/`의 `replay.py`, `review_selected.py`, `purpose-review-audit.json`, `replay-validation.json`, `corrected-analysis.json`, `corrected-report.md`.

## 검증 범위

보고서·발췌·교정·프롬프트·원문 선택 관련 검증과 신규 API 저장/표시 검증 294개가 통과했다. 광범위한 기존 API/첨부 검사는 370개 통과, 폐지된 `/api/prompts` 생성·조회 기능과 `prompt_id`를 전제로 하는 49개 실패였다. 이 실패들은 프롬프트 관리 기능 제거에 따른 기존 테스트 불일치이며 이번 변경으로 해당 기능을 복원하지 않았다. 신규 API 검증은 현재 요청 방식으로 업로드부터 실행·저장까지 확인한다. 실행 중인 8765/8766 서비스에도 적용했고, 양쪽 API에서 최신 보고서의 점검 항목 0개와 E15 검증 성공을 확인했다.

원문 일치와 참조 연결 검증은 기술적 동일성을 자동으로 보증하지 않는다. 모델의 대응 판단과 검토 범위는 계속 보고서에 구분해서 남긴다.
