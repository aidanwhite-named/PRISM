# 종속항만 따로 검색

유사문헌 검색 화면에서 전체 청구항 검색과 종속항만 따로 검색을 선택한다.
선행항을 포함한 참고 청구항, 검색할 종속항, 사용자가 확인·수정한 실제 검색 대상 문장을 구분한다.
검색 대상 문장은 직접 작성하거나 설정된 검색 모델에 정리를 요청할 수 있다.
검색 대상 문장은 선택 입력이다. 비워 두면 별도의 정리 호출 없이 검색 모델이 종속항 원문에서 추가·한정된 특징을 파악한다.
작성한 경우에는 해당 문장을 검색 기준으로 사용한다. 원문 기준 실행과 사용자 지정 문장 기준 실행을 이력·화면·보고서에 구분한다.
AI 정리는 검색을 실행하지 않으며 설명과 불확실한 인용 관계 등의 확인 사항을 표시한다.
참고 청구항·종속항 원문을 변경하면 이전 대상 문장을 비워 재확인하게 한다.

검색 순서, 검색어, 구성별·조합 검색, 문맥 활용 정도, 기술분야 확장, 재검색은 모델이 결정한다.
프로그램은 분야별 검색 경로나 후보 수·고정 평가 가중치를 추가하지 않는다.
검색 목적은 선택한 추가 특징의 대응이며, 선행항 전체를 필수 조건으로 강제하지 않는다.
모델은 특징의 대상·동작·조건·관계를 원문과 대조하고, 대응 근거와 남은 한정·적용 맥락의 차이를 설명한다.

기존 구성별 원문 검증 경로를 재사용한다. 내부 focus.mode=gap에 origin=dependent_claims를 추가하여
일반 미대응 구성 검색과 화면·내보내기에서 구분한다. 사용자가 확인한 문장은 실행 및 이력에 보존한다.
종속항 전체의 단일 문헌 대응과 추가 특징의 대응은 구분하여 표시한다.
검색 후 구성대비로 넘길 때 별도 입력한 종속항 원문도 분석 청구항에 포함한다.

정리 호출은 문헌 검색 없이 입력 크기·모델 한도·동시 실행 제한을 적용하며 입력, 출력, 사용량을
데이터 폴더의 dependent-search-drafts에 보관한다. 실패한 출력은 검색 대상에 자동 적용하지 않는다.
초기 구현 검증에서는 실제 모델과 외부 검색을 호출하지 않았다.

## 정리 버튼 호환성 수정

초기 구현은 NO_TOOLS 지원 여부만 검사하여 Codex/agy를 모델 호출 전에 거절했다.
이 두 도구는 기존 일반 텍스트 실행 경로를 사용하며, 도구 노출 자체와 실제 호출을 구분한다.
Codex의 웹 검색은 끄고 두 도구 모두 정리 호출에서 실제 도구 사용이 발견되면 결과를 거절한다.
도구를 완전히 비활성화할 수 있는 도구는 기존 NO_TOOLS 계약을 유지한다.
정리 진행 상태와 실패 메시지를 버튼 바로 아래에 표시한다.

관련 백엔드 64개·화면 15개 검사와 배포 빌드가 통과했다.
실행 중인 분석·보고서 대화가 없음을 확인한 뒤 로컬 서버를 재시작하여 수정 사항을 적용했다.
설정된 검색 모델 Codex/gpt-6.1-sol로 정리 API를 실제 호출하여 200 응답과 검색 대상 문장·설명을 확인했다.
예제 입력의 정리 소요 시간은 22.2초였다. 외부 문헌 검색은 실행하지 않았다.
검증 기록은 data/validation/dependent-draft-20261002/live-result.json에 보존한다.
