# OpenAlex 외 논문 검색 경로

OpenAlex에 DOI가 없거나 조회가 실패하거나 공개 본문을 확보하지 못하면, 검색 에이전트에 다른 저장소를 검색할 구체적인 후속 요청을 반환한다. 검색 지침도 이 경로를 이용하도록 보강했다. 각 경로 실행은 남은 검색 시간과 후보의 가치에 따라 에이전트가 선택한다.

- arXiv: 기존 검색 API를 활용하고, arXiv 식별자가 있으면 OpenAlex 없이 공식 HTML/PDF를 직접 확보한다.
- OpenReview: 공개 검색 API를 추가했다. 알려진 논문의 정확한 제목 검색과 제목 단어 검색을 지원한다. 검색 결과의 해당 논문 PDF 링크를 본문 확보 도구에 전달할 수 있다.
- CVF Open Access, ACL Anthology, CORE, 저자·기관 저장소: 제목과 핵심 방법을 이용한 웹 검색 경로를 제공한다. CORE API는 이번 환경에서 인증 없이 접근하지 못했으므로 웹 검색을 사용한다.
- Semantic Scholar는 추가하지 않았다.

검색 메타데이터와 본문 근거를 구분한다. 다른 저장소의 논문은 식별자·저자·버전 확인 전까지 기존 저널 DOI와 합치지 않는다. 제목만 입력한 경우 검증된 문헌으로 취급하지 않는다. 본문이 없는 유력 후보는 분류 보류 상태를 유지한다.

## 검증

OpenReview 공개 API에서 ArtGS 등 관련 논문을 검색했다. 일부 PDF 요청은 HTTP 403으로 실패했으므로 API 검색 성공이 본문 확보를 보장하지 않는다. arXiv의 ArtGS(2502.19459)는 OpenAlex 없이 공식 HTML 본문을 확보했다. SIGMA 논문의 공개 본문은 이번 확인에서도 확보하지 못했다.

새 회귀 테스트 7개와 관련 검색·문헌·식별자·결과 검증 테스트가 통과했고, 변경 파일의 공백 검사를 통과했다.

기존 8765 서버 재시작은 자동 승인 검토에서 차단되어 유지했다. 변경된 백엔드는 별도의 로컬 8766 서버에서 실행하고 상태 응답을 확인했다. 두 서버는 같은 PRISM 데이터 디렉터리를 사용한다.
