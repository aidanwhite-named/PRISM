# 첨부 문헌 검색의 중복 입력 개선

대상은 2026-09-29 3D 의복 모델 분석 실행 `55d4bc2f-dba8-4b38-9645-e7e8dd808035`다. 원 실행 폴더 `9f1d13ee-bf28-4f50-8314-f4ed65acc3b3`의 저장 색인과 근거 묶음을 읽기 전용으로 비교했다. 기존 실행·설정·보고서는 수정하지 않았다.

## 사용량 해석

이번 실행은 검색 7회 251,858토큰, 최종 작성 73,258토큰으로 기록됐다. 검색 단계가 합계의 약 77.5%다. 문헌을 읽고 판단하는 비용은 필요하지만, 검색 라운드마다 독립 호출로 지시·상태·유지할 원문을 다시 전달하는 현재 구현은 추가 비용을 만든다. 단순한 로컬 키워드/벡터 조회 자체가 모델 토큰을 소비하는 것은 아니다. 이 결과를 AI가 읽고 다음 행동을 정하는 호출이 사용량을 발생시킨다.

RAG에서 자료를 모델에게 보내지 않는 것은 아니다. 관련 원문을 찾아 입력을 좁히는 것이다. 작은 자료의 전체 전달보다 많은 라운드의 RAG가 항상 더 저렴하다고 볼 수 없다.

## 확인된 구현 오류와 수정

1. 긴 문단을 자를 때 줄바꿈이 겹침 구간 안에 있으면 시작 위치가 한 글자만 전진했다. 같은 짧은 구간이 수십 번 반복 생성됐다. 이제 청크 후반의 경계에서만 자르고, 없으면 전체 창을 사용한다. 원문을 요약하거나 생략하지 않고 필요한 경계 겹침을 유지한다.
2. 페이지 전문을 검색용 청크를 이어 붙여 만들었다. 검색 경계의 겹치는 부분과 위 반복 조각까지 전문에 중복 삽입됐다. 이제 색인에 보관한 원래 페이지 텍스트를 사용한다. 최종 근거의 페이지 확장, 검색 중 페이지 열람/유지, 서지 발췌에 동일하게 적용했다. 검색 후보의 구간 번호와 출처 정보는 유지한다.
3. 청킹 규칙 변경에 맞춰 INDEX_VERSION을 2로 올렸다. 새 실행에서 이전 규칙의 색인을 재사용하지 않고 재생성한다. 기존 보고서에 보관된 근거와 문장 번호는 재작성하지 않는다.

## 검증 및 남은 개선 범위

관련 테스트 384개가 통과했다. 회귀 검증은 경계 반복 방지, 검색 구간의 원문 포함·본문 보존, 페이지의 공백까지 동일한 전달, 페이지 재열람, 이전 색인 재생성, 검색 이월·범위 표시 및 보고서 문장 검증을 포함한다. 실제 모델 호출 없이 검증했다. 진행 중인 작업이 없는 것을 확인하고 로컬 8765 서버에 적용했으며 health API 정상 응답을 확인했다.

이번 수정은 확인된 중복 제거이며 검색 구조 전체를 바꾸지는 않았다. 구성별 추가 검색을 미확인 한정에 집중하고, 근거 선택이 끝난 구성을 매번 재판단하지 않도록 상태를 분리하며, 이미 충분한 근거와 미확인 범위를 함께 최종 작성에 전달하는 것은 다음 구조 개선 범위다. 호출 수를 줄이기 위해 미처리 근거를 확인한 것으로 표시하거나 단순 키워드 일치만으로 대응을 확정해서는 안 된다.
