# 키프리스 국내 특허 검색

환경설정 → **키프리스 국내 특허 검색**에서 KIPRIS Plus의 `accessKey`를 저장하고
연동을 켠다. 「특허·실용 공개·등록공보」 서비스 승인이 필요하다.
공공데이터포털의 ServiceKey API와는 다른 KIPRIS Plus OpenAPI 키를 사용한다.

기본 검색 엔진은 한국어 검색어를 최대 두 개 생성해 국내 특허·실용신안을 검색한다.
빠른 검색은 한 개를 사용한다. 키프리스 검색을 기존 후보 검색보다 먼저 수행하여
다른 검색원이 일찍 결과를 찾더라도 국내 검색 기회를 확보한다.
기존 MCP 검색 경로에서도 `kipris_search`가 제공된다.
한국어 기술 용어를 후보 정렬과 본문 BM25 검색에도 사용한다. 영어/한국어의
일치도를 별도로 계산하여 번역 용어 추가로 기존 영어 후보의 점수가 낮아지지 않게 한다.

사용자 계약에 맞춰 월 한도는 **1,000회**, 초기화는 **매월 1일 00:00 KST**다.
페이지당 실제 API 요청 한 번을 1회로 집계한다. 검색 결과 수와 응답 바이트는
집계 단위가 아니다. 연결 테스트도 검색 1회를 사용한다.

- SQLite 트랜잭션으로 전송 전에 횟수를 예약·저장하여 재시작, 동시 실행,
  별도 MCP 프로세스에서도 호출 횟수가 누락되지 않는다.
- 저장 실패 또는 한도 도달 시 외부 호출을 보내지 않는다.
- 실패·타임아웃도 보수적으로 1회로 남긴다. 자동 재시도는 없다.
- 15분 검색 캐시를 재사용하면 실제 API 요청과 차감이 없다.
- PRISM 로컬 집계이므로 다른 앱/PC 사용량은 자동 조회하지 못한다.
  포털에서 확인한 전체 횟수를 **사용량 반영**에 입력하면 외부 사용분을 반영한다.
  PRISM에서 기록한 횟수보다 낮게 설정할 수 없으며 월이 바뀐 화면의 입력도 거절한다.
- 80% 경고, 잔여 횟수, 다음 초기화 날짜, 최근 12개월 기록을 제공한다.
- 키 변경이나 연동 해제로 이번 달 사용량을 초기화하지 않는다.

키는 기존 API 자격증명과 동일하게 로컬 설정 DB에 저장한다. API 응답에는 키를
반환하지 않고 저장 여부만 반환한다. 요청은 고정 HTTPS 주소로만 보내며
리다이렉트를 따르지 않는다. 검색 감사 기록의 요청 URL에는 키를 제외한다.

검색 응답 XML을 보존하고 한국어 초록의 증거 참조를 연결한다. 검색 초록을
청구항이나 전문으로 표시하지 않는다. 전문은 기존 EPO/문헌 페이지 확보 경로에서
별도로 확인한다. 출원번호를 공개번호로 간주하지 않고, 등록일도 공개일로 대체하지 않는다.

공식 API 규격: [자유검색 freeSearchInfo](https://plus.kipris.or.kr/portal/popup/DBII_000000000000001/SC002/ADI_0000000000010162/apiDescriptionSearch.do).
실제 발급 키로의 호출 검증은 환경설정의 연결 테스트에서 수행한다.
