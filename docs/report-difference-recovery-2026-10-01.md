# 차이점 필드 누락의 복구 경로 수정

대상 실행은 `c18678ce-3c9c-4cad-8dc2-6509a7978400`이다. 원 모델 응답에는 모든 구성의 difference 필드가 없었고, 기존 근거·점수 교정으로 세 구성에만 필드가 추가됐다. 전제부/A/C/D 네 구성의 누락은 보고서 전체 점검에만 기록되어 재검토 대상 선정에서 빠졌다.

누락·형식 오류를 구성별 점검 목록으로 통합했다. 차이점만 누락된 구성은 점수·근거·대응 이유를 변경할 수 없는 difference_only 범위로 검토한다. 재검토는 검증된 기존 발췌와 구성 문언을 대조하여 실제 잔존 한정 또는 빈 문자열을 반환하며, 판단 근거를 감사 기록에 남긴다. 알려진 Provider 종료 표식 `</final>`이 마지막 메시지 파일에 붙는 경우만 파싱 전에 제거하며 임의의 추가 내용은 계속 거절한다.

실제 교정 결과 전제부/A에는 잔존 차이가 없고 C에는 영역별 픽셀 밝기와 미리 정한 임계값의 비교 관계, D에는 상태 벡터와 이미지 센서 오프셋 결정의 연결 관계가 남았다. 모든 점수·근거·기존 대응 이유는 유지됐다. 기존 보고서와 원 응답은 백업하며 원문·번역 6개를 보존한다.
