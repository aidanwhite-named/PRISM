# 미대응 구성 검색과 공개 원문 확보

일반 유사문헌 검색은 X/Y/Z를 유지한다. focus.mode=gap인 실행은 선택한 구성의
ID별로 강한 대응, 부분 대응, 비대응, 원문 확인 불가와 미확인을 구분한다.
전체 청구항은 문맥이며 전체 시스템의 차이로 특정 구성의 대응을 낮추지 않는다.

## 구성별 저장과 표시

- 서버가 검색 대상 구성을 search_review_context.json에 기록한다.
- review.component_matches의 component_id는 서버의 대상 목록과 대조한다.
  각 판정은 review.passages의 순번으로 실제 원문 발췌에 연결하며 기존의 문헌 식별,
  연속 발췌, 번역 및 대응 이유 검증을 그대로 적용한다.
- 한 구성의 발췌 검증 실패는 다른 구성의 유효한 판정을 무효로 만들지 않는다.
  임시 저장과 실패한 후속 저장은 이미 검증된 구성별 근거를 지우지 않는다.
- 화면, 실행 보고서와 이력 보고서에서 구성별 판정·차이·근거를 보여준다.
  과거 X/Y/Z 결과를 구성별 판정으로 추측해 변환하거나 기존 이력을 다시 쓰지 않는다.
  구성별 판정 자료가 없는 과거 미대응 구성 검색은 해당 구성에 미확인으로 표시한다.

## 원문 확보

- 기존 OpenAlex 경로는 주로 서지·초록이었다. literature_fetch의 full_text 요청은
  정확한 DOI 단건 조회 후 best_oa_location/locations의 공개 HTTPS 사본을 이용한다.
  PDF, 공개 저장소 페이지 및 그 페이지의 연결 PDF를 전체 남은 시간 안에서 최대
  네 주소까지 시도한다. 차단된 주소를 같은 실행에서 반복하지 않고 수집본을 재사용한다.
- 원문 다운로드와 발췌 수집은 기존 source_fetch를 통해 기록한다. OpenAlex가 제공한
  해당 문헌의 주소 연결을 검증기에 전달하되, 명시적 DOI 충돌은 다른 문헌으로 처리한다.
  메타데이터, 초록, 일반 웹페이지를 본문으로 승격하지 않는다. 공개 사본의 버전도 반환한다.
- EPO OPS의 실제 claims/description 응답을 수집 아티팩트와 passage_options로 연결했다.
  분류 근거 검증은 source_fetch와 함께 이 OPS 원문도 받을 수 있다. API 인증과 기존
  쿼터 제어를 유지하며 다른 국가·공개번호·종류코드의 패밀리 문헌은 별도 문헌이다.
- 공개 사본이 없거나 API 접근이 실패하면 후보를 미확인으로 남긴다. OpenAlex와 EPO가
  모든 논문·특허의 원문을 제공한다고 가정하지 않는다. 날짜 수집·판정은 변경하지 않았다.

사용자 요청에 따라 기능 테스트와 실제 모델 검색은 실행하지 않았다. 변경 파일의 Python
문법 확인과 화면 배포 빌드로만 확인하며, 실행 중인 PRISM을 다시 시작해야 적용된다.
