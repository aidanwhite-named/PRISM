# 복수 문헌 구성대비와 간결한 발췌

새 분석 계약을 V4로 변경했다. 구성대비에서 복수 인용발명을 허용하고, 차이점은 여러 문헌으로도 대응되지 않는 부분만 구성별 한 줄로 표시한다. 유사도는 기존 인용발명 1 기준을 유지한다. 주 문헌 점수가 낮더라도 다른 문헌으로 대응되는 내용을 차이점에 강제로 반복하지 않는다.

## 기존 출력의 과도한 분량 검토

검토 자료는 `artifacts/report-split-recovery-20260930/corrected-analysis.json`이다. 다섯 구성 중 C는 근거 6개, 원문 3,262자와 번역 1,213자이며 D는 근거 5개, 원문 3,621자와 번역 1,323자였다. E1/E8의 같은 원문은 A/C/D/E 구성에 반복 연결되어 있었다. 보완 근거 E11은 원문 1,343자·번역 653자이며 네 구성의 차이점에서 사용됐다.

일부 분량은 복합 한정의 입증에 필요하지만, 반복과 주변 설명은 과도하다. 예를 들어 E11의 ‘파이프라인은 그림 4에 도시’ 및 절 제목은 구성의 직접 근거가 아니다. 메시의 정점·에지 정의나 활성화 조건은 실제로 해당 한정에 필요한 경우에 선택하면 된다. E5의 여러 변형 수단·일반 사이즈 차트 예시는 구성 E의 ‘정점에 기초하여 면을 결정’하는 관계 자체를 직접 입증하지 않는다. 이를 넓게 인용하는 것만으로 대응 범위를 넓혀서는 안 된다. 이 검토는 보고서의 선택 범위에 대한 검토이며 원문 전체를 새로 분석한 결과나 새로운 기술적 판정은 아니다.

따라서 문장 수를 일률적으로 제한하지 않고, 추가 근거가 별개의 필수 한정·관계 또는 필수 문맥을 새로 입증하는 경우에만 선택하도록 지시를 강화했다. 의미상 중복의 최소화는 모델의 선택 기준으로, 동일 발췌의 중복 출력은 프로그램으로 처리한다.

## 표시와 검증

- 구성대비: 근거별 문헌 번호를 명시하고 대응 설명을 함께 표시한다.
- 차이점: 잔존 한정·관계만 한 줄이며 발췌·보완·도출 설명을 반복하지 않는다.
- 외국어: 필요한 번역은 보존하고 위치 뒤 확인용 원문만 최대 120자로 축약한다. 원문 전체는 검증·감사용 데이터에 남긴다.
- 한국어: 실제 대응 범위 전체를 발췌하며 위 길이 제한을 적용하지 않는다.
- 중복: 같은 문헌·페이지·원문이 다른 ID나 구성에서 다시 사용돼도 본문에는 처음 한 번만 출력한다. 이후에는 앞의 구성과 근거 번호를 참조한다.
- 검증: 다른 문헌의 근거도 실제 제공 원문으로 확인한다. 추가 문헌의 미발견·판독 불가는 주 문헌 점수와 별개로 처리한다. 주 문헌의 양수 점수를 다른 문헌의 근거만으로 정당화할 수 없다.

이전 결과를 새로운 의미로 자동 변환하지 않도록 V1–V3 재현 경로는 보존했다. 신규 실행만 V4 계약으로 생성한다. 실제 모델을 다시 호출하여 선택 분량 개선 정도를 측정한 것은 아니며, 자동 검증은 생성 지침과 보고서 조립·검증·복구 경로를 대상으로 한다.

검증: 복수 문헌·기존 보고서 호환·문장 복구·문헌 역할·원문 선택·입력 조립·내장 지침 관련 테스트 234개 통과. 신규 V4의 실행기 저장 경로와 기존 V3 경로를 모두 확인했다.
