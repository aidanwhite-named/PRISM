# PRISM 2.0.7 Windows 배포

## 변경 사항

- 유사문헌 검색의 전체 제한시간 상한을 1,200초(20분)로 확대했다. 검색 결과에서 경과 시간, 수집 문헌 수, X/Y/Z 분류 건수를 확인할 수 있다. 충분한 근거를 확보하면 일찍 종료한다.
- 검색·분석 화면과 작업 진입 화면을 개선하고, 종속항의 추가 특징 검색, 구성 생성·문헌 선택, 보고서 질문 기능을 포함했다.
- 프리즘 조각을 빠르게 세 번 누르면 열리는 숨은 관측실을 포함했다. 빛·원소·시간·별·우주·흐름 전시와 원자의 시간 여행을 제공한다.
- 현재 작업 폴더의 프론트엔드·백엔드 변경을 함께 패키징했다. 실행·설치·제거 스크립트와 설치기의 AppId는 변경하지 않았다.

## 설치와 업데이트

`PRISM-2.0.7-Setup-x64.exe`를 실행한다. 기존 설치가 있으면 실행 중인 프로그램을 종료한 뒤 업데이트한다. 설치 위치, 이력과 설정을 보존한다.

기존 검색 제한시간 설정은 유지된다. 20분으로 검색하려면 Settings의 유사문헌 검색 전체 제한시간을 1,200초로 설정한다. 신규 기본 설정은 1,200초이며, 구형 탐색·검증 설정만 저장된 환경에서는 기존 합산 시간을 유지할 수 있다.

## 배포 파일

- `PRISM-2.0.7-Setup-x64.exe`
- `PRISM-2.0.7-installer-windows-x64.zip`: 같은 설치 파일과 사용 안내.
- 두 파일의 SHA-256 확인 파일.

개발용 `PRISM-2.0.7-windows-x64.zip`은 로컬 빌드 산출물로 보관한다. 배포 설치 파일은 GitHub Releases에 업로드한다.

## 빌드 확인

프론트엔드 빌드와 설치 파일 생성을 확인하고 패키지에 현재 런타임 소스·화면 자산이 포함되는지 확인한다. 사용자 요청에 따라 이번 배포에서 별도 자동 테스트나 실제 설치·제거 테스트는 실행하지 않는다.
