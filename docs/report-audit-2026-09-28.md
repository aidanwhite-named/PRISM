## 구성대비 혼입

주 문헌은 ATT-02(인용발명 1)이다. 구성 B의 E12는 ATT-01(인용발명 2)이며 대응 이유에도 이 문헌이 사용됐다. 단순 표시 오류만이 아니므로 E12를 숨긴 뒤 91%를 그대로 확정해서는 안 된다. 수정된 조립기는 주 문헌 외의 근거를 구성대비에서 제외하고, 혼합 근거 또는 설명이 있는 구성의 유사도를 재평가 필요로 처리한다. 원 모델 점수와 응답은 감사용 구조화 데이터에 보존한다. 차이점에서 명시적으로 연결한 보완 근거는 계속 표시한다.

## 발췌 분량

A에는 E1·E2·E3·E4·E5·E7의 6개 근거가 연결됐다. 구성 문언은 한 줄이지만 키 생성, 마스크, 가역 변환, 활성 구간, 동기·블랭킹 제외 등 여러 한정을 포함하므로 무조건 한 문장만 남기는 것도 적절하지 않다. 다만 E4에는 멀티플렉서 연결 설명까지 포함되어 있고 E7은 송신기 전체 청구항을 다시 제시한다. 같은 사실을 반복하는 부분과 각 한정에 꼭 필요한 부분을 구분해야 한다. 문자 일치 검증은 기술적 관련성이나 최소 근거 여부를 판단하지 않는다.

또한 차이점에는 구성대비 근거 전체가 자동 합쳐져 설명에서 사용하지 않은 긴 인용까지 반복됐다. 이 자동 합산을 제거했다. 새 생성 지침은 가장 직접적인 짧은 근거를 우선하고, 추가 근거마다 별도로 뒷받침하는 한정을 설명하도록 한다. 원문·번역을 임의의 글자 수나 문장 수로 잘라내지는 않는다.
