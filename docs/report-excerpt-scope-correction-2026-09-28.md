## 생성 경로 변경

- 새 응답 계약 V2는 source_id와 함께 번역할 연속 원문 quote를 필수로 받는다. 프로그램은 해당 구간 안에서 일치한 범위만 출력한다. quote 누락·불일치를 전체 문단으로 대체하지 않는다. V1 저장 응답은 호환한다.
- 번역은 quote 전체와 같은 범위로 작성하며, 비연속 문장은 별도 근거로 등록하도록 지시한다. 문자 검증은 번역 의미의 정확성을 보증하지 않으며 추가 모델 검증 호출을 도입하지 않았다.
- 차이 해소 검토는 같은 구성에 명시적으로 연결된 근거와 resolution 근거를 함께 검증한다. 다른 구성의 근거를 추정하지 않는다.
- 근거를 찾지 못했다는 insufficient 자체는 작성 오류가 아니다. 근거 없는 supported, 없는 ID, 불일치 발췌, 연결되지 않은 문헌 사용은 계속 검증한다.
- 내부 처리 경로와 실제 적용 단계를 검토하고, 직접 개시·결합 추론·잔존 차이·자료 부족을 구분하도록 지침을 보완했다. 형식 명칭 차이만으로 결합 검토를 종료하거나, 주기별 갱신을 주기 내부 비반복으로 확대하지 않도록 했다.
