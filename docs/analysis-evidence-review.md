# 구성대비 보고서: 부분 롤백 후 실행 경로

2026-09-17 별도 AI 근거 재검토와 보고서 재조립을 실행 경로에서 제거했다. 재검토 응답 형식 오류와 반복 호출로 인한 시간 초과를 줄이기 위한 부분 롤백이다.

## 현재 동작

- 전체 인라인은 모델이 최종 보고서를 한 번 생성한다.
- 로컬 검색은 기본 최대 5라운드로 근거를 확보한 뒤 최종 보고서를 한 번 생성한다. 검색 결과를 재검토용 후보로 따로 수집하지 않는다.
- 구성별 분석·문헌 매핑 블록을 읽고 기존 출력 검사를 적용한다. 별도 AI 평가로 보고서 본문·점수·문헌 순서를 다시 만들지 않는다.
- 탈락 후보의 설명·번역·제외 이유는 출력하지 않도록 지시한다.
- 저장된 과거 프롬프트가 구형 근거 비교 블록을 출력해도 해당 블록만 본문에서 제거한다.

## 유지한 검색 개선

- 새로 반환된 결과를 검토한 뒤 종료한다. 마지막 호출은 반환된 근거의 검토·확정에 사용하고 새 조회를 실행하지 않는다.
- 추가 검색은 근거가 부족한 구성을 우선한다.
- 구절·문맥 열람도 확인 범위에 기록하며 페이지 전체 열람과 구분한다.

## 기록과 검증

기존 보고서와 재검토 기록은 그대로 보존한다. 남아 있는 `analysis_evidence` 모듈의 재검토·재조립 함수는 새 보고서 실행에서 호출하지 않으며, 새 실행에는 해당 재검토 산출물이 생기지 않는다.

회귀 테스트는 전체 인라인 1회, 검색 2라운드 예제에서 총 3회의 모델 호출과 모델 보고서·점수·문헌 순서 보존을 확인한다. 별도 재검토가 호출되지 않는지도 검사한다. 이 검증은 실행 경로를 확인하며 실제 특허 판단의 정확도를 보장하지 않는다.
