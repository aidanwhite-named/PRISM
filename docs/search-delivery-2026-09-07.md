# 5회 검색 안에서 전달량 줄이기 — 2026-09-07

검색 회차 5회, 페이지 전체 열람 80쪽, 라운드 결과 56,000자, 최종 근거
패키지 100,000자 및 실행별 바이트 한도는 유지했다. 의미 검색도 유지했다.

## 변경

- 검색 프롬프트는 추가 조회로 확인할 미확인 한정을 짧게 쓰고, 같은 목적의
  검색과 자동 이월 요청을 반복하지 않도록 정리했다. 마지막 결과를 확인하고
  확정하는 데에도 회차가 필요함을 명시했다.
- 검색 후보는 최대 900자 발췌와 출처를 먼저 전달한다. 모든 후보에 앞뒤 문맥을
  선제적으로 붙이지 않는다. 부정·예외 조건, 문장 잘림, 지시어로 해석이 불확실한
  구간에는 문맥 확인을 요구한다.
- `read_chunk`는 이미 반환한 문헌·구간의 전문과 같은 페이지의 앞뒤 문맥
  (각 최대 500자)을 제공한다. 더 넓은 범위가 필요하면 기존 페이지 열람을 쓴다.
  전체를 전달할 공간이 없으면 요청을 이월한다. 구간 열람은 페이지 전체 열람으로
  집계하지 않으며, 문맥에 나온 다른 구간의 인용 권한을 자동으로 부여하지 않는다.
- 같은 호출·문헌·페이지에서 정확히 포함되는 원문·문맥은 원문 필드와 문자
  범위를 참조한다. 참조가 더 짧을 때만 사용한다. 다음 호출에는 원문을 다시
  보내며, 반환되지 않은 내용을 원문 참조 대상으로 등록하지 않는다.
- 최종 패키지의 원문·문맥 보존 및 페이지 확장 정책, 누락 경고는 유지했다.

## 동일한 저장 응답 재생

원본 실행 자료 `c4480609-6ab0-407b-a0d6-b2d627281177`의 읽기 전용 인덱스,
동일한 청구항, 의미 검색 및 저장된 AI 응답 5개로 변경 전·후 실행기를 비교했다.
변경 전 미처리 요청과 패키지 수치가 저장된 원본과 일치했다.

| 항목 | 변경 전 | 변경 후 |
|---|---:|---:|
| 검색 회차 | 5 | 5 |
| 미처리 요청 | 24 | 2 |
| 고정 검색 후보 중 미전달 건수 | 112 | 3 |
| 최종 근거 | 10 | 10 |
| 페이지 전체 열람 / 반복 열람 | 8 / 4 | 8 / 4 |
| 제외·부분 수록 페이지 | 0 | 0 |

후보 수는 구성·검색 요청별 목록의 집계이며 서로 다른 원문 구간 수가 아니다.
최종 10개 근거의 출처·원문·앞뒤 문맥·관련성 설명은 동일하다. 더 많은 검색
후보가 전달되어 일부 근거의 검색 채널·채널 순위 기록은 달라졌다.

저장 응답 재생은 전달 구현의 비교다. 새 프롬프트에 대한 AI의 반응이나
5회 내 정상 확정을 증명하지 않는다. 변경 후에도 2건이 남아 경고가 유지됐다.

## 실제 AI 및 보고서 생성

앱의 청구항 1 실행 `049915cd-c56c-4cd1-9eee-b076ded50bea`에서 자료를 재사용해
`agy / gemini-3.7-flash-low`로 새로 분석했다. PDF 4건의 내용과 청구항을 유지했다.
생성된 실행은 `4baccf24-5a45-4eb9-871f-a38cb9cc2ecb`이다.

- **5회 내 검색 정상 확정**, 미처리 요청 0건. 마지막 추적 이벤트가 정상
  `finalize`이며 `finalize_fallback`은 없다.
- 구간 열람 9건, 페이지 전체 열람 1쪽. 각 구성의 4개 문헌 검색 결과에는
  예산으로 미전달된 후보가 없다. 이는 전 문헌 전문을 모두 검토했다는 뜻은 아니다.
- 최종 근거 11건, 출처 검증에서 거절된 근거 0건.
- 보고서 생성 성공, 구성별 분석 블록 파싱 오류 없음.

**최종 패키지 용량 제한은 별도로 남았다.** 97,782자 / 104,611 bytes가 수록됐고,
주변 페이지 ATT-04 p.4·p.7, ATT-03 p.11·p.9가 제외됐다. ATT-04 p.2는
6,364자 중 4,240자만 수록되어 2,124자가 빠졌다. 선택된 근거 11건 자체는
유지됐지만, 이 페이지 확장 누락 때문에 최종 manifest는 `partial`,
`budget_exhausted=true`다. 따라서 화면의 예산 경고가 모두 해결됐다고 주장하지 않는다.

이 실제 실행은 5회 내 완료 가능성을 확인한 사례이며 모든 자료의 완료나
보고서 판단 품질의 동등성을 보장하지 않는다. 모델의 선택은 실행마다 달라진다.

## 검증과 반영

- 검색·이월·구간 열람 관련 최종 검사 125건 통과. 원문 참조를 실제 결과에서
  찾아 복원하는 검사, 다른 문헌·페이지 간 공유 방지, 호출 간 원문 재전달,
  부정 조건 문맥 보존, 예산 초과 이월과 미반환 원문 참조 방지를 포함한다.
- 백엔드 전체 검사에서 검색 MCP 하위 프로세스 테스트 1건은 프로젝트 루트에서
  실행되어 `app` 모듈을 찾지 못했다. 해당 검사를 `backend`에서 재실행해 통과했다.
  나머지 전체 검사는 통과했다. 실제 CLI opt-in 검사 16건은 제외했다.
- 실제 AI 검증 후 페이지 원문 참조의 구성 ID를 결과에도 명시하도록 보강했으며,
  위 최종 관련 검사로 확인했다.
- 실행·대기 작업이 없는 상태에서 8765 서버에 수정본을 반영했다.
