# 구성별 판단과 보고서 작성 분리

최신 보고서 `b03c1ed6-1e47-4c0e-9895-4b1d6ee59e81`에서 사전 검토의 SENS MLP 근거가 최초 작성에서 선택되지 않고, 부분 대응과 전체 요구의 미확인이 혼동된 사례를 바탕으로 생성 경로를 변경했다. 모델과 추론 강도를 변경하지 않는다.

## 생성 흐름

1. 청구항 해석과 문헌별 원문 처리 흐름을 정리한다. 문헌 제목·번호도 실제 원문 문장에 연결한다.
2. 주 문헌을 고르기 전에 각 구성을 별도 호출로 대비한다. 전체 청구항 문맥과 다른 구성의 입력·출력은 유지하며, 각 문헌의 입력·동작·출력·전체 연결·명시 조건을 각각 기록한다. 부분 사실이 확인된 것과 전체 관계가 미확인인 것을 같은 상태로 합치지 않는다.
3. 구성별 상세 대비를 바탕으로 주 문헌을 선정한다. 기존 고정 번호·주 문헌은 유지한다.
4. 각 구성에서 필요한 주 문헌·보완 문헌, 주 문헌 자체의 점수, 대응 설명과 잔존 차이를 확정한다. 이 단계는 원문 번호를 다시 선택하지 않는다. 선택한 문헌에서 앞 단계가 확인한 원문 사실은 프로그램이 그대로 연결한다.
5. 마지막 작성 호출에는 확정된 구성 판단과 선택 원문만 전달한다. 번역·요약만 허용하며 문헌·원문 선택·점수·차이점은 응답에서 받지 않는다. 프로그램이 확정 데이터와 번역을 합쳐 V5 보고서를 조립한다.

`backend/app/comparison_generation.py`가 새 구성별 생성과 조립을 담당하고 `comparison_review.prepare(..., segmented=True)` 및 실행기에 연결했다. 기존 명시적 블록·이전 보고서 재현 경로와 `segmented=False` 호출은 유지한다. 청구항 해석 형식 자체를 반환하지 못하는 이전 제공자의 호환 경로도 유지되며 검토 미완료 안내를 남긴다. 유효한 청구항 해석 이후 새 구성별 단계가 실패하면 기존 전체 재작성 경로로 돌아가지 않고 실패 원인과 사용량을 보존한다.

## 근거와 실패 처리

- 문헌별 후보에 있는 본문·보충자료 페이지와 인접 페이지를 제공한다. 후보가 없는 문헌은 해당 제공 원문을 모두 검토할 기회를 준다.
- 전체 제공 원문의 페이지 목록에서 추가 열람을 요청할 수 있다. 최대 두 번 확장하며 범위가 부족하면 완료로 추정하지 않는다. 후보 페이지 범위와 원래 전체 전달/검색 발췌 범위를 구분하여 기록한다.
- 구성별 입력 한도를 넘으면 임의로 원문을 자르지 않는다. 취소·실행 오류·원문 번호·문헌 연결 오류를 통과로 바꾸지 않는다. 잘못된 구성별 응답에는 해당 구성만 한 번 교정을 요청한다.
- 선택 문헌의 확인한 문장 번호를 원문 순서로 정렬하고 연속 구간별로 분리한다. 문장 추가·삭제·문헌 이동 없이 처리하고 번역 전에 범위를 확정한다. 각 범위의 근거 번호는 프로그램이 문헌 참조에 연결한다.
- 작성 응답에 분석 변경 필드가 있거나 선택 범위의 번역이 누락·중복되면 조립을 거절한다. 원문·연결 및 독립 기술 검토는 계속 수행한다. 독립 기술 검토에서 근거와 이유를 갖춘 판단 교정은 별도 감사 경로로 남는다.
- `comparison-review/audit.json`에 구성별 대비·확정 판단·보고서 계획을 남긴다. `writing-response.txt`는 마지막 작성 응답, `analysis-response.txt`는 확정 계획과 번역을 합친 보고서 데이터다. 실제 마지막 호출의 프롬프트와 입력 크기도 저장한다.

## 실제 모델 확인

원 실행과 같은 네 문헌, `gpt-6-luna / medium`으로 구성 D·E를 별도 검증 폴더에서 실행했다. 전체 청구항 문맥은 보존했다. 기존 보고서와 DB 결과를 교체하지 않았다.

초기 시험에서는 모델이 떨어진 문장을 한 발췌로 묶거나 교정 과정에서 사실을 다시 누락했다. 이에 범위 분리와 선택 문헌의 확인된 사실 연결을 프로그램으로 옮겼다. 최종 시험은 앞서 실제 모델로 검증한 D·E 상세 대비를 재사용하고 판단 확정·번역을 재실행했다. 주 문헌은 기준 실행의 ATT-02를 유지하여 해당 변경의 효과를 확인했다.

- E: `ATT-01-P15-T14`가 최종 근거 E18로 보존됐다. MLP 매핑이 있다는 사실과 청구항의 ‘특정 벡터’ 지시 대상이 불명확하다는 문제를 구분했다.
- D: ATT-04의 특징 융합을 보완 근거로 선택하고, 그 처리가 청구된 트랜스포머 디코더에 해당하는지의 불확실성을 별도로 남겼다. 모든 대체 문헌을 추가하지 않고 문헌 등록 목록은 네 개를 유지했다.
- 최종 두 구성의 원문 근거 18개 모두 검증, 보고서 항목 연결 문제 0개다. 번역·요약 호출의 입력은 17,102 토큰이었다. 전체 일곱 구성의 원 실행 작성 입력 133,909 토큰과는 범위가 달라 직접적인 절감률로 비교하지 않는다.

이 확인은 누락 근거 보존과 단계 분리를 검증한 사례다. 전체 일곱 구성의 신규 생성, 신규 주 문헌 선정 및 독립 기술 검토까지 포함한 동일 조건 전체 비교는 수행하지 않았다. 기술적 대응·점수의 정확성을 보증하지 않는다. 모델 호출 수와 처리 시간은 구성 수·추가 열람에 따라 늘어날 수 있다.
