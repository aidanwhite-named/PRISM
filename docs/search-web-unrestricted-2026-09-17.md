# 웹 검색의 고정 질의·열람 금지 제거

사용자의 골격 모델 청구항으로 검증한다. 이전 턴의 몰입형 비디오 청구항과 구분한다.

## 제거한 내용

- 웹 검색 지시의 `exact short queries`, 질의당 정확히 한 번/총 두 번, 질의 추가·수정 금지, 페이지 열람 금지, 청구항 분석 금지, 검색 직후 즉시 반환 지시.
- 최종 문헌 3개, snippet 160자 지시와 수신 결과 8개/1200자 잘라내기.
- Provider의 기존 검색·열람 정책을 검색 3회 정책으로 덮어쓰던 코드.
- 검색 도구 이름 세 개 이외의 도구를 즉시 중단하던 중복 검사. 이제 원래 Provider 정책의 WebFetch/read_url_content 및 웹 산출물 view_file 열람이 가능하다.
- DB 후보가 한 건이라도 있으면 웹 검색을 생략하던 조건.
- 관계 검색·일반 검색·확장에 흩어진 웹 검색 호출. 기존 일반 검색의 한 번의 웹 호출로 모았다.
- 웹 호출의 별도 30초 상한. 전체 검색의 수집 잔여 시간 안에서 실행한다.

웹 검색에 원 청구항, 사용자가 선택한 전략, 참고용 질의와 DB 후보의 제목·초록·URL을 전달한다.
이전에는 질의만 전달했으므로 금지 문구만 지워도 모델이 원래 청구항을 충분히 이해할 수 없었다.
검색식과 열람 문헌의 선택은 같은 Provider 실행 안에서 모델이 한다. 새 재검색 단계나 보정 호출은 없다.

기존 전체 시간·분류 시간 예약·Provider의 검색 정책은 유지한다. 일반 로컬 파일 접근이나 셸 실행까지 여는 변경은 아니다.
소스 결과는 `web_reported`로 보존하며 직접 인용 검증 성공으로 자동 승격하지 않는다.
화면의 웹 조회 한 줄은 탐색 실행을 뜻한다. 모델이 실제 호출한 검색어와 URL은 inference의 tool_calls/tool_events에서 확인한다.
시간 초과 시에도 호출 시도 기록을 남기도록 기존 usage 기록에 tool_events를 보존한다. 이는 새 제어 단계가 아닌 감사 기록이다.

## 검증

- `backend/evaluation/search_cases.json`에 원 골격 모델 청구항을 `coupled_joint_limits`로 추가했다.
- 사용자가 제공한 논문의 DOI·URL과 특허번호는 평가 자료에만 넣었다. 검색 모델 입력에는 넣지 않는다.
- 기본 설정 agy / gemini-3.8-flash-medium, 심층 검색 120초로 비교했다.
- 변경 전 `f5d0f05c-beff-43a0-a4f5-0d1e1310e73f`: 115.844초, 후보 20개, 선별 8개 응답, 알려진 논문 미발견. 웹 호출 30초 상한 초과.
- 변경 후 `2acfab8e-826a-4bdb-a33b-cc6a417e7ec3`: 102.031초, 후보 20개, 선별 8개 응답, 알려진 논문 미발견. 웹 호출은 수집 마감까지 실행했으나 결과 반환 전에 시간 초과. 계획 캐시 및 질의 캐시 4개를 사용했으므로 시간 단축률로 비교하지 않는다.
- 호출 기록 보존 후 `857af45f-4a43-4abc-8212-011cb63686db`: 약 65초의 웹 구간에서 `search_web` 9회가 관측됐다. 모델은 한국어 원문 표현 → 일본어 부모/자식 뼈 표현 → 영어 skeletal model/parent bone/child bone → 검색 중 얻은 표현·번호를 이용한 질의로 변경했다. 평가용 정답 번호는 입력하지 않았다. 페이지 열람 호출은 이 구간에서 관측되지 않았고 최종 records 반환 전 시간 초과했다. 질의 수정과 세 번째 이후 검색이 중단되지 않는 것은 실측했지만, 페이지 열람은 Provider별 모의 실행 검사 범위다.

관련 백엔드 93개 테스트와 `git diff --check` 통과. 이번 변경은 프론트엔드 파일을 추가 수정하지 않았다.
테스트는 기존 DB 후보가 있어도 웹 검색하는 동작, 원 청구항·전략 전달, Claude/agy/Codex의 검색·열람 정책,
세 번째 이후 호출과 반환 문헌 보존, 불완전 JSON의 완결된 문헌 보존을 포함한다.

변경 후 실제 검색이 시간 안에 유효한 문헌 결과를 반환했는지와, 코드가 검색·열람을 허용하는지는 별개다.
단순히 제한을 없앴다는 이유로 검색 품질 개선이나 Claude와 동등한 결과를 주장하지 않는다.

실행 원본은 `%LOCALAPPDATA%/PRISM/runs/<실행 ID>/`, 평가 요약은
`%LOCALAPPDATA%/PRISM/diagnostics/open-web-20260917/`에 보존한다.
