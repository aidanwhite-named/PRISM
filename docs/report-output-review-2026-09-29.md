## 출력 오류와 수정

- 원문에서 복원한 단락번호를 위치에 표시하면서 발췌 안의 번호도 그대로 출력했다. 표시용 발췌·번역에서 해당 번호를 제거하고 위치에만 표시한다. 검증용 원문은 보존한다.
- `feature`는 모델 응답에 있었지만 보고서 조립에서 누락했다. 구성 기호·등급 아래에 청구항 문언을 복원하고, 발췌 다음에는 대응 이유를 표시한다.

- 발췌가 `(f)` 같은 열거 항목에서 끊기면 다음 페이지 근거와 번역 범위를 점검하도록 경고한다. 이는 이번에 확인한 유형의 탐지이며 모든 번역 의미·범위 오류를 자동 검증한다는 뜻은 아니다.
