## 프로그램 문제

- 기존 지침이 차이점 설명 안에 주 문헌 근거를 다시 인용하게 했고, 조립기도 이를 출력했다. 지침을 추가하는 것만으로는 반복을 막기 어려웠다.
- 새 차이점 계약은 `gap`, `evidence`, `supplements`, `derivation`, `remaining_difference`, `conclusion`이다. `supplements`는 보완 문헌별 번호·근거·대응 설명을 분리한다. 주 문헌을 보완 문헌으로 등록할 수 없다. 주 문헌 근거는 검증에 사용하되 차이점에 직접 발췌를 출력하지 않는다.
- 주 문헌의 부족한 한정에서 바로 보완 문헌 근거·대응 이유·남는 차이로 이어진다. 자체 도출은 이미 대응된 내용을 반복하지 않고 필요한 변경과 기술적 이유만 쓴다.
- 다른 문헌이 구성대비에 혼입되어 점수를 보류할 때는 `원문 재확인 필요` 대신 `주 문헌 기준 재평가 필요`로 표시한다. 실제 판독 실패와 판단 오류를 구분한다.
- E12는 존재하지 않는 선택 구간 번호를 사용했다. 같은 문헌의 실제 전달 원문에서 전체 발췌가 유일하게 일치하면 위치 번호를 정정할 수 있도록 확장했다. 다른 문헌의 번호·생략·문구 변형·여러 일치 위치는 자동 복원하지 않는다.
- 생성 지침에는 대상의 역할·전달 경로·조건·시간 범위 구분, 부재 판단 전 더 직접적인 실시예 확인, 사용자 구성 문언 보존을 추가했다. 이번 사례의 기술 용어나 결론을 일반 지침에 고정하지 않았다.
