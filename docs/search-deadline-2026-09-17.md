# 탐색 마감과 후보 분류 시간 확보

## 문제

모델 주도 검색에서 전체 300초를 탐색에 모두 사용하면 후보를 저장했어도 분류·결과 JSON이 없다. MCP의 남은 시간 안내만으로는 native 웹 검색을 반복하는 모델을 멈추게 할 수 없었다.

## 변경

- 전체 예산 안에서 탐색 195초, 분류 예약 100초, 저장 여유 5초를 배분한다. API별 호출 순서와 질의·확장은 계속 모델이 결정한다.
- 탐색 중 자료를 읽으면 잠정 분류와 이유도 즉시 저장하도록 안내한다. MCP가 보여 주는 남은 시간은 탐색 구간 기준이다. 탐색 종료 10초 전부터 새 MCP 조회를 시작하지 않으며 후보 저장은 허용한다.
- native 웹 검색에도 동일하게 탐색 실행의 최대 시간을 적용한다. 모델이 일찍 분류 결과를 완성하면 별도 호출 없이 종료한다.
- 탐색이 끝났는데 분류가 남았으면 같은 설정의 모델을 최대 한 번 더 호출한다. 새 검색 도구·MCP 없이 **보존된 자료만** 전달한다. 실제 남은 전체 시간에서 저장 여유를 뺀 값을 제한 시간으로 사용한다.
- 저장 후보, 아직 선택되지 않은 API 조회 문헌, 확보한 초록·본문과 근거 참조를 전달한다. 모델이 명시적으로 제외한 문헌은 다시 넣지 않는다. 입력 크기는 문헌별 텍스트를 줄여 제한하고, 축약 여부를 표시한다. 모델이 보지 못한 원문을 읽었다고 주장하지 않는다.
- 모델이 X/Y/Z에 해당하는 그룹과 구체적인 이유를 판단한다. 자료 부족과 검토 결과 관련성 낮음은 별도로 표시한다. 내부 기존 A/B/C 저장 형식과 화면 X/Y/Z 대응은 유지한다.
- 응답은 입력 후보 식별자와 대조한다. 새 문헌 생성, 중복 식별자, 그룹·판정 상태 불일치는 거절한다. 일부 후보가 누락되면 받은 분류는 보존하되 전체 완료로 표시하지 않는다.
- 계획된 탐색 시간 종료 뒤 분류가 완료되면 작업은 정상 종료한다. 원문·근거 검증 부족과 검색 범위의 한계는 별도로 남긴다. 사용자 취소, 인증/사용량 오류, 분류 실패는 정상 종료로 숨기지 않는다.
- 분류 입력·출력·프롬프트·사용량을 실행 산출물로 남긴다. 두 호출의 사용량을 합산하고 중단된 호출의 사용량이 불완전하면 그대로 표시한다.

## 한계

검색 제한 시간은 모델 실행 기준이며 프로세스 시작·종료와 저장에 짧은 추가 시간이 들 수 있다. 예약 시간을 확보해도 모델 자체의 응답 지연·잘못된 JSON·자료 부족까지 없앨 수는 없다. 이 경우 확보한 후보와 완료된 분류를 보존하고 미완료 사유를 표시한다.

분류는 문헌의 신규성·진보성에 관한 법적 결론이 아니다. 자동 발견 성능 개선과 이번 마감 처리 개선은 별도로 평가한다.

## 검증

- 관련 백엔드 154개, 결과 화면 14개 테스트 및 프런트엔드 build 통과.
- 테스트는 전체 시간 내 분류 예약, native 탐색 시간 제한, 새 조회 없이 모델 분류, 완료 후 timeout 해제, 취소·전체 마감 시 새 호출 금지, 후보 ID/그룹 일관성, 일부 분류 누락 보존, 불완전 사용량 집계, 마감 직전 MCP 조회 차단과 저장 허용을 검증한다.
- 첫 실제 실행 `922b701c-0fd5-4759-bcac-c90e316d50f2`: 약 197초에 탐색에서 분류로 전환, 288초에 후보 38건 평가 완료. Z 4건, 나머지 34건은 자료 부족 또는 관련성 낮음으로 평가했다. 다만 탐색 도중 Gemini가 도구 스키마 폴더에서 `find_by_name`을 호출하여 전체 상태는 TOOL_POLICY_VIOLATION으로 유지했다. 분류 성공으로 정책 오류를 덮지 않았다.
- 이를 보완해 Gemini 프롬프트에 사용 가능한 MCP 설명 파일의 정확한 경로를 나열하고 `find_by_name/list_dir` 없이 바로 읽도록 안내했다. 허용 도구 정책은 넓히지 않았다.
- 보완 후 실제 실행 `3c3a6963-64e8-4fac-bff8-3ca66718c473`: 약 197초에 분류로 전환, **256초에 SUCCEEDED**. 후보 44건 전부 평가: **X 1건, Y 1건, 자료 부족 12건, 관련성 낮음 30건**. 도구 정책 오류는 없었다. 목표 JP7475618B1/WO2012111622A1은 발견되지 않았으므로 이번 성공은 시간 내 분류·결과 완성의 성공이다. 모델의 그룹 판단과 원문 근거 검증은 별개이며, 이 실행의 공식 원문 직접 인용 검증 건수는 0이다.
- 실제 실행 집계는 [재현 스크립트](artifacts/joint-search-comparison-20260917/summarize_deadline_runs.py)와 [결과](artifacts/joint-search-comparison-20260917/deadline-runs-summary.json)에 보존한다. 목표 JP/WO 문헌 발견 여부는 시간 내 분류 완료 여부와 구분한다.
