# 가져온 페이지의 grep_search 범위 판정

실패 작업 `cb63285d-1123-42d6-b105-3a7586138413`의 웹 검색 8회는 모두 성공했다.
agy는 성공한 `read_url_content` 14번 단계의 저장 폴더에서 `Abstract`,
`Applicant`, `Assignee`를 찾으려고 `grep_search`를 3회 호출했다. 해당 폴더에는
실제로 `content.md`와 가져오기 결과 안내인 `output.txt`만 있었다.

기존 정책은 페이지 저장본의 `view_file`만 범위를 검사해 허용했다. grep은
일반 로컬 검색 도구로 분류되어 실행 전체가 도구 정책 위반으로 실패했다.

## 수정

- `grep_search`를 이름만으로 허용하지 않고 `content_read_tools`에 추가했다.
  이번 대화에서 성공한 가져오기 단계의 `content.md` 또는 그 전용 폴더만 허용한다.
- 폴더 검색은 `content.md`와 선택적인 `output.txt` 외에 파일·하위 폴더가
  없고, 항목이 외부 파일로 연결되지 않았을 때만 허용한다. 상위 steps·대화·brain,
  다른 대화, 실패한 가져오기, 일반 로컬 파일은 여전히 위반이다.
- 스트림 파서가 실제 `SearchPath`와 `Query`를 감사 기록에 남긴다. 범위 검사에
  사용하는 경로는 화면용 500자 제한으로 자르지 않는다.
- grep은 검색 질의 횟수가 아닌 본문 확인 횟수에 포함한다. 매칭 여부와 출력
  형식을 알 수 없으므로 grep만으로 `content_read=true`로 승격하지 않는다.
  `view_file`도 완료 성공이 확인된 경우에만 본문을 읽었다고 기록한다.
- 실행 프롬프트에 허용된 grep 범위와 필요한 구간을 view_file로 확인하는 규칙을
  추가했다. agy는 도구를 사전 차단할 수 없어 이 검사는 계속 사후 감사다.

## 검증

관련 Provider·스트림·도구 정책·검색 API·보고서 계약 테스트 **254개 통과**.
저장된 실패 실행의 원본 stdout를 이벤트 순서대로 재생하면 grep 3회 모두
`scope_ok=true`, `scope=read_url_content:14`로 판정되고 evaluator도 통과한다.
이것은 저장된 보고서의 성공 상태를 임의로 덮어쓴 것이 아니다.

유휴 상태를 확인한 뒤 서버를 재시작해 수정 사항을 적용했다. 같은 청구항·모델·
검색 깊이로 별도 유사검색 검증 실행을 생성했다. 진단 기록은
`%LOCALAPPDATA%/PRISM/diagnostics/grep-scope-20260914/`에 보존한다.

첫 실제 검증 실행 `4ef44a79-b2ee-4f9f-9269-d83c8572ff05`는 도구 정책은 통과했으나
정상 JSON 코드 블록 뒤에 옛 채널별 검색 기록이 붙어 `INVALID_OUTPUT`으로 실패했다.
`search_manifest.parse_payload`가 이 정확한 조합만 수용하도록 보완했다.
추가 기록이 web/epo/kiwee/literature의 queries/fetches 문자열 배열일 때만 허용하며,
두 번째 후보 보고서·중복 JSON 키·잘못된 형식·임의 산문은 여전히 거부한다.
실제 저장된 응답을 새 파서와 근거 검증기에 통과시켜 후보 4건의 처리를 확인했다.

두 번째 전체 검색도 grep 정책 위반은 없었지만, 모델이 JSON 뒤에 산문 형식의
구형 기록을 붙여 형식 검증에 실패했다. 조사 결과 `_AGY_ALLOWLIST_RULES`에
구형 `[PRISM_SEARCH_LOG_V1]` 출력을 요구하는 모순된 지시가 남아 있었다.
이 지시를 candidates가 있는 JSON 객체 하나로 통일했다. 임의 산문을 버리고
성공으로 취급하는 완화는 하지 않았다. 해당 안내를 포함한 추가 회귀 테스트
142개가 통과했고 서버도 다시 반영했다.

마지막 짧은 실제 도구 검증은 agy가 검색 호출 뒤 빈 최종 응답으로 끝나 완료하지
못했다. 따라서 이번 변경의 정책 판정과 파서·프롬프트 회귀 검증은 통과했지만,
최종 버전의 전체 유사검색 보고서 생성 성공까지 확인한 것은 아니다.
