# 미대응 부분에 필요한 인용발명만 순차 선택

## 기존 보고서 확인

가장 최근 보고서 실행 `4dbc8810-cf59-4c7c-83d9-87ec38ffce89`의 저장 보고서와
구조화 분석을 읽기 전용으로 확인했다. 보고서 인용번호와 첨부번호는 다르다.
주 문헌은 ATT-03(Air Meshes), 인용발명 2는 ATT-01(EP 1242978 B1),
인용발명 3은 ATT-02(Edge Flips)다.

- 구성 (A): 주 문헌 E1만 support다. 인용발명 2의 E4와 3의 E5는 모두
  contrast이며, 설명도 두 발췌가 공기 메쉬의 품질 측정에 해당하지 않는다고
  명시한다. 따라서 2로 부족해서 3으로 보완한 결과가 아니다. 잔존 차이가 있다.
- 구성 (B): 주 문헌 E1/E2가 support다. 설명은 주 문헌이 대상·동작·관계에
  대응한다고 판단하고 difference는 빈 문자열이다. 인용발명 2의 E3와
  3의 E5는 모두 contrast로 추가되었다. 주 문헌으로 대응이 끝난 뒤에도
  다른 후보의 비교 설명을 나열한 사례다.

이 확인은 저장된 판단과 근거 용도의 검사다. 원문 전체의 기술적 대응을 새로
판정하거나 기존 보고서를 수정하지 않았다.

## 변경

공유 지침 `backend/app/reference_selection.py`를 신규 보고서 작성, 구조화 출력,
근거 연결 교정, 독립 기술 검토, 전체 재작성에 적용했다.

1. 주 문헌으로 필수 한정과 관계가 모두 대응하면 그 구성의 비교를 종료한다.
2. 남은 부분에 가장 직접적이고 폭넓게 대응하는 보완 문헌 하나를 선택한다.
   하나로 모두 보완할 수 있으면 여러 문헌으로 나누지 않는다.
3. 주 문헌의 미대응 부분과 보완 문헌의 실제 내용을 근거 ID로 직접 연결해 쓴다.
4. 선택한 문헌들로도 남은 부분이 있을 때만 다음 문헌을 추가하고 추가 필요성을 쓴다.
5. 대응이 끝난 부분의 대체 후보와 탈락 후보의 support/contrast 설명을 나열하지 않는다.
   선택한 문헌의 대응 범위를 설명하는 데 필요한 contrast는 보존한다.

주 문헌 선정용 문헌별 사전 검토와 문헌 매핑은 유지한다. 사전 검토 목록을
각 구성에 전부 출력하는 것으로 해석하지 않도록 최종 입력에도 명시했다.
최적 보완 후보를 첨부순·번호순으로 강제하지 않으며 기존 고정번호는 보존한다.
독립 검토는 불필요한 추가 문헌과 보완 부분 연결 설명의 누락도 수정 대상으로 삼는다.

유사도 수치만으로 대응 완료를 판단하거나 근거를 자동 삭제하지 않는다.
기술적 대응과 선택은 원문을 대조하는 모델의 판단이며 주 문헌 점수는 유지한다.
기존 보고서의 원응답·저장 파일·DB는 변경하지 않는다.

## 검증

공유 지침의 생성·교정·검토 경로 전달을 확인하고, 독립 검토에서 주 문헌만으로
대응이 끝났다고 판단한 경우 불필요한 support/contrast 문헌을 제거한 재작성이
반영되는 회귀 테스트를 추가했다. 해당 테스트는 주 문헌 점수·문헌 매핑·원결과의
보존과 구성요소 탭에서 추가 문헌이 빠지는 결과를 확인한다.
실제 모델의 신규 보고서 생성은 실행하지 않았으므로 새 지침에 따른 선택 품질은
자동 테스트만으로 확정하지 않는다.

관련 테스트 366개 통과. 변경 내용의 공백 검사도 통과했다.

## 실행 중 프로그램 반영 상태

8765 서버는 프로젝트의 Python 환경에서 실행 중이며 자동 재로딩 옵션이 없다.
실행 중인 작업이 없음을 읽기 전용 DB 조회로 확인했다. 새 지침을 로딩하기 위한
서버 재시작 명령은 자동 승인 검토에서 `blocked by policy`로 거절되었고,
구체적인 정책 사유는 반환되지 않았다. 명령 실행 자체가 거절되어 서버를 중지하거나
다시 시작하지 않았다. 우회 실행은 하지 않았으며 프로그램을 다시 실행해야 반영된다.
