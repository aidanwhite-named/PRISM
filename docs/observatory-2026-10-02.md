# PRISM 숨은 관측실

화면 아래 프리즘 조각을 짧은 간격으로 세 번 누르면 열린다. 검색·분석 작업과 독립된 교육용 탐험 화면이다. 프리즘의 입체 회전은 3차원 꼭짓점을 화면으로 투영한다. 마우스·터치 드래그, 방향키, 회전 슬라이더를 지원한다.

## 전시와 조작

| 장소 | 조작과 이야기 |
| --- | --- |
| 빛의 방 | 빛줄기 선택, 200–1,600 nm 파장 슬라이더, 진동수·광자 에너지, 다섯 문제의 빛 게임 |
| 원소의 서가 | 118개 원소의 실제 표 위치, 기호·이름·용도 검색, 개별 역사·용도·창작 농담, 이야기 그림, 다섯 단서의 원소 탐정 게임 |
| 1초의 탄생 | 1초 재생 및 구간 슬라이더, 정확한 기준 진동 횟수, 초미세 에너지 준위의 개념 그림 |
| 별의 다음 장 | 성운부터 무거운 별의 잔해까지 여섯 장면, 중성자별/블랙홀 비교, 펄사 관찰 방향과 시범 회전 속도 |
| 우주의 눈금 | 그림 위 휠, 방향키, 길이 눈금 슬라이더, 쿼크 탐사 눈금에서 관측 가능한 우주까지 12개 대표 단계 |
| 흐름의 비밀 | 유선함수로 정한 속도장과 입자 경로, 섞임 조절, 카오스·엔트로피의 구분, AI 유체 연구의 범위와 발표 시점 |
| 다음 우주의 문 | 다섯 장의 CCC 이야기와 단계 슬라이더, 이전 이온과 다음 이온의 개념 연결 |

본 화면에서 과학 자료를 자동 호출하거나 특허 검색을 실행하지 않는다. 원소의 발견 기록만 `prism.observatory.discoveries.v1`에 로컬 저장한다. 관측실은 처음 열 때 별도 파일을 불러온다. 방을 나가거나 닫으면 애니메이션·크기 감시·휠 이벤트가 정리된다. 동작 줄이기 설정을 존중하며, 사용자가 애니메이션을 멈출 수 있다. Escape와 닫기 버튼을 지원하고, 닫으면 원래 조각으로 포커스를 돌린다.

## 사실과 표현의 경계

자료 확인 기준: 2026년 10월 2일. 원문을 전재하지 않고 한국어 이야기와 그림을 직접 작성했다. 각 전시와 원소에 근거 링크를 제공한다.

- 광자의 진동수 `f = c / λ`, 에너지 `E = hf`는 SI 상수로 계산한다. 색과 파형의 크기는 설명용이다. UV/IR 색은 가상 표시이며, 380–780 nm 가시광 경계는 교육용 근사다. 회전 프리즘은 광선 추적 시뮬레이터가 아니다. [NASA 전자기 스펙트럼](https://science.nasa.gov/ems/)
- 세슘-133의 교란 없는 바닥 상태 초미세 전이 진동수 9,192,631,770 Hz를 사용한다. 원자핵의 물리적 왕복 운동이라는 설명을 하지 않는다. 파형은 느린 그림이고 재생은 브라우저 시간이며 실제 원자시계가 아니다. [BIPM SI 상수](https://www.bipm.org/en/measurement-units/)
- 모든 원소의 역사·성질·용도는 [Royal Society of Chemistry의 원소 자료](https://periodic-table.rsc.org/)를 검토했다. 실제 용도에는 합금, 화합물, 동위원소가 포함된다. 초중원소에 존재하지 않는 일상 용도를 붙이지 않는다. 그림은 이야기의 상징이고 농담은 창작이다.
- 은의 기호와 Argentina의 라틴어 뿌리 연결은 [아르헨티나 정부 자료](https://www.argentina.gob.ar/pais/territorio/denominacion)를 참조한다. 김감불·김검동은 [연산군일기 49권, 1503년 5월 18일](https://sillok.history.go.kr/id/kja_10905018_003)의 기록이다. 납에서 은을 제련하는 것을 원자핵을 바꾸는 연금술로 소개하지 않는다.
- [바나듐](https://periodic-table.rsc.org/element/23/)의 Vanadis 이름, 화합물의 여러 색과 일부 멍게류의 농축 능력을 연결한다. 멍게의 겉색이 모두 바나듐 때문이라고 단정하지 않는다. 미소를 멍게에 빗대는 문장은 색·이름을 이어 만든 시적 농담이다.
- 질소고정 자체를 하버가 발명했다는 표현을 쓰지 않는다. 자연의 질소고정과 [하버의 암모니아 합성](https://www.nobelprize.org/prizes/chemistry/1918/haber/facts/), [보슈의 산업화](https://www.nobelprize.org/prizes/chemistry/1931/bosch/facts/)를 구분한다.
- 별의 여섯 단계는 무거운 별의 대표 경로다. 태양의 결말이나 모든 붕괴에 대한 하나의 공식이 아니다. 펄사는 관찰자를 빛줄기가 스치는 등대 비유로 표현한다. 블랙홀은 강착 원반과 중력에 의한 빛의 휘어짐을 표현한 도식이다. [NASA 별의 일생](https://science.nasa.gov/mission/webb/star-lifecycle/), [NASA 펄사](https://science.nasa.gov/mission/hubble/science/science-behind-the-discoveries/hubble-pulsars/)
- 스케일 그림은 대표 길이에 따라 장면을 바꾸고 크기를 재조정한다. 한 실제 지도의 연속 확대가 아니다. 쿼크의 실제 크기·내부 구조나 전체 우주의 크기를 안다고 표현하지 않는다. [NASA 우주](https://science.nasa.gov/universe/)
- CCC는 연구 가설이다. 등각 재조정을 물리적인 우주 수축이나 원자와 우주의 물리적 동일성으로 소개하지 않는다. [Meissner·Penrose, The Physics of Conformal Cyclic Cosmology (2025)](https://arxiv.org/abs/2503.24263)
- 입자 그림은 `ψ = sin(x)sin(y) + a sin(2x+0.7t)sin(y+0.4t)`로 정한 발산 0의 속도장을 따른다. Navier–Stokes의 압력·점성 방정식을 푸는 그림이 아니다.
- 2025년 AI 연구는 IPM 및 경계가 있는 3D Euler 방정식의 특정 자기유사 해 탐색으로 설명한다. [Discovery of Unstable Singularities](https://arxiv.org/abs/2509.14185)
- 최신 자료는 별도 장으로 둔다. 2026년 9월 8일의 특정 외력 조건 Navier–Stokes 특이점 증명 발표와 9월 11일 Clay의 평가 절차 안내를 구분한다. 모든 흐름의 닫힌 형태 일반해로 소개하지 않는다. [OpenAI 발표](https://openai.com/index/navier-stokes-solution/), [Clay 안내](https://www.claymath.org/year_type/2026/)

## 확인

원소 118개와 중복 없는 표 위치, 광자 단위 계산, 세슘 진동 횟수, 게임의 정답·오답 진행, 원소 이야기·저장, 시계 정리, 별의 갈림길, 휠 범위, 애니메이션 정리를 자동 검사한다. 실제 브라우저에서 드래그 회전, 파장 선택, 전시 이동과 화면 배치를 별도로 확인한다. 검증 화면은 `artifacts/observatory/`에 저장한다.

## 생활 속 원소 1–54 확장

수소부터 제논까지 각 원소에 생활 이야기, 작동 원리, 관찰 질문, 물질 형태, 개별 SVG 삽화를 추가했다. Royal Society of Chemistry의 54개 공식 원소 페이지(`https://periodic-table.rsc.org/element/{원자번호}/`)에서 용도를 확인했고, 원문의 표현이나 사진을 복제하지 않았다. 크로뮴의 스테인리스 보호 피막 설명은 [worldstainless](https://worldstainless.org/about-stainless/properties/corrosion-properties/)를 추가로 참고했다.

그림 54개는 모두 다른 생활 장면을 직접 그린 설명용 삽화다. 수소 버스, 붕규산 주전자, 스테인리스 숟가락, 망가니즈 철도, 제논 플래시와 이온 추진기를 비롯한다. 각 캡션은 기체·이온·합금·화합물·동위원소 등 실제 사용 형태를 구분한다. 테크네튬처럼 가정용 물건에서 드문 원소는 병원 진단 영상으로 연결했다. 팔라듐 커패시터 전극처럼 모든 현대 제품에 적용되지 않는 용도에는 범위를 명시했다.

첫 선택은 수소다. 1번부터 차례로 읽기와 이전/다음 원소를 제공하며 54번 뒤에는 수소로 돌아온다. 생활 단어와 나트륨·칼륨·불소 등 익숙한 별칭으로 검색할 수 있다. 원소 선택 시 이야기 카드로 이동하며 동작 줄이기 설정을 존중한다. 은·바나듐·질소의 기존 특별 이야기는 추가 장으로 보존했다. 55–118번은 기존 이야기와 상징 그림을 유지한다.

54개 내용의 완전성·공식 출처, 접근 가능한 개별 그림 54개와 중복 없는 도형, 전체 순서 탐색·순환·장 제목 잔류 방지, 생활 검색·별칭·기존 원소 연결을 자동 검사했다. 전체 프런트엔드 174개 검사 통과 후 변경 부분을 다시 검사했다. 실제 브라우저에서는 1–54 순서와 모바일 카드 배치를 확인했다.

## 시간의 두 이야기: 잠시, 나라는 모양

1초의 탄생 안에 세슘 시계와 원자의 시간 여행을 선택하는 메뉴를 추가했다. 새로운 이야기는 별 → 바람 → 물 → 풀 → 동물 → 숨결 → 조상 → 지금의 나 → 다시 세상 → 다음 생명, 열 장면으로 구성한다. 같은 ID를 가진 탄소 상징 점 96개가 위치를 바꾸며, 선택한 금빛 점은 계속 유지된다. 시간축과 장면 버튼으로 직접 탐색하고 자동 재생·일시정지·지금으로 돌아오기를 지원한다. 지금의 모양/시간의 눈으로 선택은 선택한 점의 전체 경로 표시를 바꾼다. 재생 시간은 장면당 약 3.8초이며 역사적 연대나 물리적 소요 시간을 나타내지 않는다.

시의 중심 문장은 “나는 잠시, 나라는 모양”, “지금으로 읽으면 나. 시간으로 읽으면 세계”다. 범아일여에서 영감을 얻은 창작 시와 개별 장면의 짧은 시를 제공한다. 앞선 세대와 미래 생명을 같은 세계의 물질 순환 안에서 생각하되, 특정 원자가 실제 조상을 거쳤다고 확인하거나 기억·인격이 재탄생한다고 설명하지 않는다.

과학 설명은 [NASA의 별과 원소](https://science.nasa.gov/astrobiology/learning-resources/alp/are-we-really-made-of-star-stuff/), [NOAA의 탄소 순환](https://oceanservice.noaa.gov/facts/carbon-cycle.html)을 검토했다. 몸의 수소 대부분은 초기 우주에서 유래하며, 물 장면의 탄소는 H₂O 자체가 아닌 물속 탄소 물질이다. 범아일여의 맥락은 [Stanford Encyclopedia of Philosophy의 Śaṅkara](https://plato.stanford.edu/entries/shankara/)를 참조한다. 철학적 동일성과 화학적 순환을 동일한 과학 명제로 취급하지 않는다. 원문 전재 없이 한국어로 직접 썼다.

동작 줄이기 및 관측실 전체 일시정지를 존중한다. 수동 조작·재생 종료·화면 전환·닫기에서 프레임을 정리한다. 위치 범위와 장면 사이 연속성, 같은 점의 정체성 유지, 선택·관점 전환, 재생 수명, 세슘 시계와 전환을 자동 검사하고 실제 데스크톱·모바일 화면을 확인했다.
