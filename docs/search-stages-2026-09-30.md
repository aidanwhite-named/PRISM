# 후보 탐색 4분 + 원문 검증 2분

기존 기본값은 전체 300초이며 첫 실행에 남은 시간의 60%를 쓰고 나머지를 원문 확인·재검색에 사용했다. X/Y/Z는 내장 검색 지침에 이미 있었지만 구조화된 원문 검토 결과에는 저장되지 않았다.

현재 동작:

- `search_timeout_seconds`: 후보 탐색 상한, 기본/최대 240초. 기존 DB에 300초 이상이 남아 있어도 읽기와 실행 시 240초로 제한한다.
- `search_verification_seconds`: 별도 검증 상한, 기본/최대 120초. 탐색에서 남은 시간을 검증에 이월하지 않는다. 전체 실행 예산은 두 상한의 합이다. 프로세스 종료와 결과 저장에는 소량의 추가 시간이 걸릴 수 있다.
- 탐색 단계는 유력 후보 5~10개를 목표로 가볍게 선별하고 관련성 순서로 저장한다. 5건을 강제로 채우지 않는다. 검증에는 저장 순위와 검토 상태를 반영한 상위 10건까지 전달하며 전체 후보 기록은 보존한다.
- 검증 단계에서는 기존 후보의 원문만 확인한다. MCP 신규 검색·인용 확장은 차단한다. Provider 기본 웹 도구는 검색과 URL 열람을 함께 제공할 수 있어 기존 후보 확인에만 쓰도록 지시한다.
- 원문 발췌 검증을 통과한 `review.group`을 X/Y/Z로 표시하고 정렬한다. X/Y는 strong, Z는 partial과 일치해야 한다. 미검증·비관련 문헌에는 그룹을 강제로 부여하지 않는다.
- 날짜 조건을 충족한 X가 저장되면 실행 중인 호출을 종료한다. 공개일 미확인 또는 기준일 이후 X는 조기 종료를 일으키지 않는다. 이미 확인한 Y/Z와 미검증 후보는 보존한다.
- 분류는 AI의 기술적 판단이다. 프로그램 검증은 실제 읽은 해당 문헌의 원문 발췌 일치·번역 존재·필수 항목을 확인한다. 법적 판단을 확정하지 않는다.

테스트는 시간 배분·기존 설정 상한·원문 근거와 날짜를 통과한 X의 조기 종료·미검증 후보 보존·MCP 단계 제한·그룹 순서와 화면 표시를 다룬다. 실제 유료 검색의 평균 시간·토큰 절감률은 측정하지 않았다.
