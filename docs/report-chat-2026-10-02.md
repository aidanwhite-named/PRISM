# 현재 보고서의 질문·답변과 수정·보완 대화창

보고서 화면 상단의 ‘보고서 수정·보완’ 버튼을 우측 하단의 접을 수 있는
대화창으로 바꿨다. 결과가 있는 구성대비 보고서에서 사용할 수 있다.

## 동작

- 현재 청구항, 이전 청구항, 저장 보고서, 문헌 매핑, 검증된 원문 발췌와
  완료된 대화를 현재 보고서의 AI 도구·모델에 전달한다.
- 포함한 문헌의 읽을 수 있는 본문 전체가 입력 예산 안에 들면 함께 전달한다.
  예산을 넘으면 보고서의 검증된 발췌로 범위를 제한하며 모델과 화면에 명시한다.
  보고서·질문·대화 기록을 조용히 자르지 않는다. 이것 자체가 넘으면 호출 전에 거절한다.
- 보고서별 질문과 답변은 `report_chat_turns`에 저장한다. 다른 보고서에 대화가
  섞이지 않으며 실행 이력 삭제 시 해당 대화도 함께 삭제한다.
- 같은 보고서의 답변은 하나씩 작성한다. 요청 번호로 재전송 중복을 막고,
  여러 화면에서 동시에 질문하는 경우도 DB의 부분 고유 인덱스로 제한한다.
- 대화창을 접어도 작성 중인 답변을 계속 확인한다. 실행 중 답변을 중단할 수
  있고 실패한 질문은 다시 보낼 수 있다. 프로그램 종료 시 미완료 상태를 복구한다.
- 원본 보고서는 질문으로 수정하지 않는다. ‘대화 내용으로 수정·보완’을 누르면
  기존 CONTINUED 경로로 대화와 추가 요청을 넘긴다. 분석 준비 화면에서 요청을
  확인한 뒤 분석을 시작하여 새 보고서를 생성한다.
- 원문과 이전 보고서·대화의 지시를 실행하지 않도록 구분하며 도구 없는 호출 정책,
  기존 실행 슬롯·입력 한도·실행 결과 검사와 사용량 기록을 사용한다.
- Codex·agy도 보고서 생성과 동일한 실행 방식으로 대화를 지원한다. CLI가 도구를
  완전히 끌 수 없다는 이유만으로 질문 접수·실행을 막지 않는다. 도구 사용 금지
  요청과 실제 호출에 대한 결과 검사는 유지하며, 실제 도구 호출이 있으면 답변을
  성공으로 저장하지 않는다.

## 확인

관련 백엔드 테스트 132개 통과. 보고서 간 분리, 검증·제외 근거 구분, 후속 대화,
원본 보고서 보존, 중복 요청, 동시 질문 제한, 입력 예산, 중단·시간 초과,
프로그램 재시작 복구, 이력 삭제와 기존 보고서·정답 라이브러리 API를 확인했다.

전체 화면 테스트 146개 통과 후 접힌 대화창의 답변 확인을 추가하여, 마지막
대화창·보고서 수정 전달 관련 19개 테스트를 다시 확인했다. 최종 화면 빌드와
변경 내용 공백 검사도 통과했다. Enter 전송, 한글 조합 입력, 줄바꿈, 네트워크
재시도, 대화 복원, 수정 요청 전달을 포함한다.

실제 브라우저에서 기본 화면과 390×844 화면의 배치를 확인했다.
별도 데이터 폴더와 검증용 응답을 사용하는 8878 서버에서 질문 전송·답변 표시를
확인했으며 실제 AI 모델은 호출하지 않았다. 기존 보고서와 운영 DB를 바꾸지 않았다.
검증 화면은 `docs/artifacts/report-chat-20261002/chat-preview.png`에 저장했다.

현재 8765 서버는 자동 재로딩 없이 실행 중이다. 앞선 서버 재시작 명령이
자동 승인 검토에서 `blocked by policy`로 거절되어 이를 다시 시도하거나
우회하지 않았다. 최종 코드의 API와 새 대화 테이블은 프로그램을 재실행할 때
로딩된다. 별도 검증 서버는 운영 서버를 대체하지 않는다.
