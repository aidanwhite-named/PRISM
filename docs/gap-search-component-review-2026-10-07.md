# 선택 구성 검색의 검토 누락 방지

선택 구성 F/H/I를 검색한 실행에서 후보 문헌마다 관련 구성만 저장되어, 7개 후보 모두 나머지 구성의 판단이 누락됐다. 기존 화면은 판단 누락과 발췌 검증 실패를 모두 `미확인`으로 표시했고 모델이 종료하면 검토 보완 없이 성공 처리했다.

## 동작

- 선택 구성 검색은 저장된 각 후보의 선택 구성 전부를 검토한다. 한 구성의 강한 대응이 다른 구성의 검토를 생략할 이유가 되지 않는다.
- 모델 종료 후 누락·검증 실패를 확인하고, 기존 문헌·출처·정상 판단을 이어받아 남은 전체 시간 안에서 검토를 보완한다. 새 시간 예산을 부여하지 않는다.
- 추가 검토에 연속 두 번 진전이 없으면 반복 호출을 멈추고 구성 검토 미완료로 보존한다. 시간 종료·사용자 취소에도 남은 항목을 임의로 판단하지 않는다.
- 선택 구성의 검토·검증이 남으면 작업은 `SEARCH_REVIEW_INCOMPLETE`로 끝난다. 확보한 결과·정상 근거는 보존하며 검색 이어가기를 지원한다. 일반 전체 검색의 종료 정책은 유지한다.

## 상태와 근거

- 미검토: 저장된 유효 판단이 없음.
- 검토함 · 근거 검증 필요: 판단은 저장됐으나 원문 연결·발췌 검증 등을 통과하지 못함.
- 검토 완료: 원문 검증을 통과한 강한 대응·부분 대응·비대응 또는 검토 범위 내 대응 근거 없음.
- 검토 불가 · 원문 확인 불가: 실제 자료 확보·열람 불가와 사유가 기록됨. 검토 생략을 이 상태로 채우도록 지시하지 않는다.

`not_found`는 실제 검토한 후보 본문의 `reviewed_capture_ids`, 검토 범위 설명과 미대응 한정을 요구한다. 초록·다른 문헌·알 수 없는 수집 번호는 통과시키지 않는다. 원문 수집 기록의 범위 확인은 모델의 의미 판단을 보증하지 않으며, 문헌 전체 부재로 확대하지 않는다. 화면과 내보낸 보고서에 같은 상태와 검토 범위를 표시한다.

과거 저장 결과의 누락 판단은 새로 만들어 넣지 않는다. 화면은 기존 판단·검증 상태에서 검토 여부를 구분하고, 사용자가 검색을 이어가면 남은 검토를 보완한다.

## 검증

선택 구성 누락 자동 보완, 부분 저장 시 기존 판단 보존, 근거 검증 실패와 미검토 구분, 본문 범위에 한정된 미발견 판단, 시간 종료, 보완 진전 없음, 미완료 작업의 결과 보존·이어가기·완료 전환을 테스트한다. 일반 검색·종속항 검색 회귀 테스트와 프런트엔드 상태 표시·이어가기 테스트 및 빌드를 함께 수행한다.
