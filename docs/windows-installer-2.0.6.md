# PRISM 2.0.6 Windows 배포

## 변경 사항

- 구성대비에서 여러 인용문헌을 함께 사용할 수 있고, 차이점은 전체 대비 후 남은 미대응 부분만 표시한다.
- 설명·발췌·자료 번호의 연결을 검증하고, 대응 근거와 비교·미발견 참조의 역할을 구분한다.
- 번역이 필요한 문헌은 번역 범위와 짧은 원문 확인 발췌를 구분하며 발췌 중복을 줄인다.
- 청구항의 기능·관계를 먼저 해석하고 각 문헌을 독립적으로 검토한 다음 주 문헌을 선정한다. 보고서 생성 후 모든 구성을 다시 검토하고 확인된 불일치를 교정한다.
- 분석·검색 지침을 프로그램에 포함한다. 이전 프롬프트 편집·선택 설정은 사용하지 않는다.
- 검색·원문 확인·분류·재검색은 전체 제한시간 안에서 진행한다. 진행 기록과 최종 도구 기록의 중복 집계를 방지한다.

## 설치와 업데이트

`PRISM-2.0.6-Setup-x64.exe`를 실행한다. 기존 설치가 있으면 프로그램을 종료하고 같은 설치 파일을 실행한다. 설치 위치를 재사용하고 분석 이력과 설정을 보존한다. 기존 버전을 먼저 제거할 필요는 없다.

설치기는 동일한 AppId를 유지한다. 제거 프로그램은 설치할 때 자동 생성되며 Windows의 설치된 앱, 시작 메뉴 또는 `제거.cmd`에서 실행한다. 기존의 데이터 정리·의존성 소유권 확인 규칙을 유지한다.

## 배포 파일

- `PRISM-2.0.6-Setup-x64.exe`: 설치·업데이트 및 제거 프로그램 생성.
- `PRISM-2.0.6-installer-windows-x64.zip`: 같은 설치 파일과 사용 안내.
- 각 배포 파일의 SHA-256 확인 파일.
- `PRISM-2.0.6-windows-x64.zip`: 개발자용 실행 환경 검증 아카이브. 일반 다운로드는 설치 파일을 사용한다.

## 검증

격리된 사용자 경로에서 Windows 설치·제거 스크립트, 이전 2.0.5 설치기로부터의 업데이트, 이력·가상환경·기존 파일 보존, 다운그레이드 차단, 설치 준비 실패 처리와 실제 제거 프로그램을 검증한다. 별도로 2.0.6 신규 설치와 제거를 확인한다.

배포 아카이브를 한글·공백 경로에 풀어 새 가상환경을 만들고, 전역 Python·Node 경로 없이 실행기·상태 API·화면 파일이 동작하는지 검증한다. 테스트는 실제 사용자 데이터와 CLI 계정을 변경하거나 유료 모델을 호출하지 않는다.
