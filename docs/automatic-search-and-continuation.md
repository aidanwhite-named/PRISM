# 기본 검색과 정밀 검색 이어가기

- 검색 화면은 `정밀 검색` 체크박스 하나를 사용한다. 기본값은 해제이며 내부 depth는 `deep`이다. 기존 API의 `fast`는 호환성을 위해 유지한다.
- 기본 검색은 하나의 총예산(기본 120초) 안에서 초기 탐색과 심층 확장을 수행한다. 초기 탐색은 fast 시간 예산(기본 45초)을 적용해 후속 검증 시간을 남긴다.
- X는 한 문헌의 모든 구성에 대해, Y는 대응 관계에 대해 검증된 원문 인용이 있어야 조기 종료한다. 초록만 있는 분류나 기준일 이후 문헌으로는 종료하지 않는다.
- 기본 검색 완료 후 검증된 X/Y가 없으면 정밀 검색 제안 팝업을 표시한다. 닫아도 기존 결과는 유지되며 결과 화면에서 다시 이어갈 수 있다.
- 정밀 검색 체크 시 처음부터 exhaustive 예산(기본 300초)으로 실행한다. 검증된 결과를 찾으면 조기 종료할 수 있다.
- `POST /api/jobs/{id}/continue-search`는 원래 결과를 보존하는 후속 실행을 만들며 같은 원본에 대한 반복 요청은 같은 후속 실행을 반환한다.
- 후속 실행은 후보, 검색어 이력, 원문 passage, 판정, 사용량을 복원한다. 계획과 초기 검색을 다시 실행하지 않는다. 시간·호출·토큰 예산은 누적하며 사용자 응답 대기 시간은 제외한다. 원문 근거는 후속 실행에도 보존 참조를 등록한다.
- arXiv 관련 기술어가 있으면 초기 탐색에서 OpenAlex와 함께 소수의 arXiv 질의를 실행한다. 다른 분야에서는 검증된 X/Y가 없을 때 심층 단계에서 arXiv를 한 번 보완적으로 검색한다. 같은 실행에서 이미 조회한 arXiv는 반복하지 않는다.
- arXiv 공개 검색 API에는 API 키가 필요 없다. 검색 응답은 서지·초록·원문 링크이며 PDF 확보는 별도 단계이다.

실제 전체 검색 품질과 평균 소요시간은 주제·외부 서비스·LLM 응답에 따라 달라진다. 이번 검증은 엔진/API 회귀 테스트와 화면 동작 테스트, 프런트엔드 빌드, 키 없는 arXiv 단일 조회이다.
