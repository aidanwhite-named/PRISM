# 검색·후보 검토·종료의 자율 판단

유사 문헌 검색은 새 문헌을 찾는 일과 확보한 후보를 읽어 평가하는 일을 한 세션에서 수행한다. 모델이 다음 행동의 기대 가치를 판단해 탐색, 본문 검토, 분석 단서로 재검색, 종료를 선택한다. 단계별 시간 배분·검색 횟수·후보 수는 고정하지 않는다.

## 실행과 완료

- 유사 문헌을 확보하지 못했거나 일부 후보·구성이 미검토여도 모델이 마무리하면 정상적으로 종료한다. 제한시간과 사용자 취소는 계속 실행을 중단한다.
- 모델 종료 후 선택 구성의 미검토 항목 때문에 별도 세션을 자동 실행하지 않는다. 사용자가 검색 이어가기를 요청하면 기존 후보·판단·원문 기록을 재사용한다.
- 실행 완료와 검토 완료를 구분한다. 미검토 후보가 있어도 작업은 `SUCCEEDED`이며 manifest에는 `verification_incomplete`와 구성별 실제 검토 상태를 남긴다. 실행 오류와 실제 조회 기록이 없는 경우는 계속 실패한다.
- 후보가 없다는 사실이나 비치명적인 경고만으로 실행을 실패 처리하지 않는다. 빈 결과에는 검색 범위에서 문헌을 확보하지 못했음을 표시하고 문헌 부재로 단정하지 않는다.

## 모델에 전달하는 자료

시스템 지시와 기본 검색 전략의 성공 조건·반복 지시를 정리했다. 후보 분석도 검색 성과를 높이는 행동이며, 추가 행동의 가치가 낮으면 결과가 없어도 종료할 수 있음을 기본 역할에 포함한다. 별도의 감독 모델이나 주기적인 판단 호출은 추가하지 않는다.

저장 응답은 검토 상태·남은 차이·발췌 검증 오류를 반환한다. `next_action`으로 계속 실행을 지시하지 않으며 발췌 교정은 `repair_options`와 `repair_hint`, 원문 확보의 대체 경로는 `fallback_searches`로 제공한다. 미검토 목록과 대체 경로는 선택을 위한 자료다.

실제로 확인하지 않은 구성은 미검토로 남긴다. 이를 비관련·검토 불가·검토 범위 내 근거 없음으로 자동 변경하지 않는다. 원문 식별자·발췌·번역 검증과 잠정 유력 후보 표시는 유지한다.

이 변경은 같은 날 작성한 `gap-search-component-review-2026-10-07.md`의 자동 보완과 미완료 작업 실패 정책을 대체한다. 과거 `SEARCH_REVIEW_INCOMPLETE` 결과의 표시·이어가기는 호환성을 유지한다.

## 검증 범위

자동 테스트는 빈 결과의 정상 종료, 경고가 있는 빈 결과, 한 세션 내 자발적 추가 검토, 일부 구성의 미검토 상태 보존, 명시적 이어가기를 통한 검토 완료, 시간 제한·사용자 취소, 실제 조회 요구 및 원문 근거 검증을 확인한다.

모델의 검색 품질과 토큰·시간 절감은 실제 모델 실행으로 별도 비교해야 한다. 비교 시 쉽게 찾는 사례, 찾기 어려운 사례, 본문을 읽어야 가치가 드러나는 후보, 원문 접근이 막힌 사례를 포함하고 호출 수·토큰·시간뿐 아니라 유사성 판단의 근거와 후보 품질도 평가한다.
