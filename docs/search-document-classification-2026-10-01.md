# 문헌 연결과 문헌별 분류 저장

최근 검색에서 출판사 주소로 저장된 RocSync 후보와 arXiv HTML 본문을 연결하지 못했고,
HTML 본문도 일반 웹페이지로 처리되어 발췌 검증에 사용할 수 없었다. 다른 문헌의
조회가 분류 저장보다 먼저 진행되면서 시간 종료 시 확보한 원문도 미분류로 남았다.

## 변경

- DOI, arXiv 번호, 특허 공개번호를 개별 식별자로 정규화한다. 복합 번호 문자열도
  각각 인식한다. 실제 수집 페이지의 인용 메타데이터, canonical 주소, 해당 논문의
  PDF 연결로 출처를 연결한다. 제목 유사성이나 참고문헌 링크로 문헌을 합치지 않는다.
- arXiv HTML URL의 LaTeXML 문헌 영역과 본문 절이 있는 경우에만 본문으로 추출한다.
  초록 페이지와 일반 웹페이지는 본문으로 승격하지 않는다. 기존 수집본은 원본 바이트를
  재사용해 새 추출 형식으로 갱신할 수 있다.
- 주소가 달라도 같은 문헌이면 후보를 합치고 기존 식별자, 출처 주소, 검증된 분류를
  유지한다. 임시 저장이나 실패한 후속 발췌가 성공한 분류를 지우지 않는다.
- 검색·원문 확인·분류 저장·재검색을 하나의 모델 세션에서 자유롭게 수행한다.
  단계별 시간 배분, 후보 5~10개 할당, X 발견 시 강제 종료를 제거했다. 충분한 근거가
  확보되고 추가 탐색의 가치가 낮으면 모델이 일찍 종료할 수 있다.
- 분류 저장 전 다른 문헌 조회를 막던 제어와 마지막 20초 조회 차단을 제거했다.
  문헌별 저장 상태를 확인하고 수시로 저장하도록 안내하되, 실패한 문헌의 교정 여부와
  다음 행동은 남은 시간과 가치에 따라 모델이 결정한다.
- 저장 요청의 문헌 형식을 개별적으로 확인한 뒤 각 문헌을 디스크에 반영한다.
  형식 오류나 문헌별 검증 처리 오류는 failed_findings에 남기고 다른 문헌을 계속 저장한다.
  분류 처리 중 식별자 연결 객체가 발췌 순번으로 덮어써지던 오류도 수정했다.
- 설정은 search_total_seconds 하나로 합쳤다(10~360초). 기존 두 설정은 각각의 이전
  상한 안에서 합산해 이어받고, 새 전체 시간을 저장하면 그 값을 우선한다. 기존 이력의
  단계별 시간 표시와 종료 사유는 유지한다.
- 화면과 보고서에서 본문 미확보와 분류 저장 미완료를 구분한다. 발췌 검증 실패도
  문헌 연결, 본문 범위, 원문 수집 기록, 발췌 불일치로 구분한다.

날짜 판정 규칙과 공개일 수집 방식은 변경하지 않았다. 기존 검색 이력의 분류를
자동으로 확정하거나 실제 모델 검색을 실행하지 않았다. 별도 분류용 모델 호출도
추가하지 않았으며, 전체 제한시간 안에서 모델이 다음 행동과 종료 시점을 결정한다.

사용자 요청에 따라 기능 테스트는 실행하지 않았다. Python 문법 확인과 화면 배포용
빌드만 수행했다. 실행 중인 PRISM 백엔드를 재시작해야 변경된 진행 제어가 적용된다.
