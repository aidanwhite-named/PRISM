# 관계 중심 검색 우선 실행과 기존 검색의 연결

후속 변경: 검색 전략 선택란 숨김, 검색 깊이 이동 및 자동 인용·피인용 조회는 [인용 검색 연결 기록](citation-expansion-2026-09-17.md)에 정리했다. 아래 미구현 설명은 이 기록 작성 당시의 상태다.

## 적용한 흐름

청구항 분석 → 관계 중심 짧은 검색어 2개 → EPO 검색(미설정이면 웹 검색) → 소수 후보 전문·관련 구간 확인 → X 확인 시 종료 → X 미확인 시 기존 특허·논문 검색 → 깊이와 잔여 예산에 따라 확장.

검색어는 기존 `plan` LLM 호출에서 함께 생성한다. EPO에는 중요도 순서의 앞 네 단어를 AND 검색으로 전달한다. 긴 생성 검색어는 로그에 보존한다. 첫 특허 검색이 비었을 때 웹 검색을 추가할 수 있으며, 시간·질의·LLM 예산을 고려한다. 출처의 검색 순위만으로 X를 붙이지 않는다.

첫 단계에서는 여러 구성에 걸친 초록의 용어 대응으로 최대 두 문헌을 고르고, 전문에서 관련 구간을 뽑아 검증한다. 이 선택 점수는 관계 일치 판정이 아니다. X로 종료하려면 같은 문헌에 대해 모든 분해 구성의 explicit/semantic 대응, 원문과 대조된 인용문, 전문/청구항/설명 범위, 공개일 조건을 충족해야 한다. 전체 청구항도 검증기에 전달한다. LLM 판정의 오류 가능성이 없어지는 것은 아니다.

첫 단계의 시간 상한은 60초이고, 전체 예산에서 빠른 검색은 20초, 심층·정밀은 45초를 후속 경로에 남긴다. 남은 시간이 작으면 첫 단계의 별도 검증을 생략하고 확보한 후보를 기존 경로에서 검토한다. 후보를 초기화하지 않는다. 오류·미검증·초록만의 X 판정도 후속 검색 사유이며, 문헌 부재로 표현하지 않는다.

## 검색 전략과 인용 검색의 의미

화면의 **검색 전략**은 검색어 생성·문헌 평가에 적용하는 사용자의 지침 프롬프트다. 기본 프롬프트 하나가 제공되며 `프롬프트 관리`에서 추가·편집한다. 검색 엔진 종류나 빠른/심층/정밀 모드 목록이 아니다. **검색 깊이**가 시간·후보·호출 예산을 정한다. 이번 자동 경로는 전략 프롬프트와 별개로 엔진에서 실행되며, 화면과 결과에 설명 및 전환 이력을 추가했다.

현재 인용·피인용 자동 검색은 없다. 지침에 언급된 것을 구현된 기능으로 오해하면 안 된다. 현재 후속 확장은 대체 검색어, 용어, IPC 및 정밀 모드의 다음 검색 페이지다. 인용은 seed가 참조한 문헌, 피인용은 seed를 참조한 후속 문헌을 따라가는 별도 발견 경로로 추가할 가치가 있다. 처음부터 매번 실행하기보다 좋은 seed는 있으나 X가 확인되지 않을 때 한 단계로 제한하는 것이 적절하다. 가족 문헌과 인용 관계는 서로 다른 관계다.

## 검증과 남은 한계

- 관련 백엔드 테스트 63개, 프런트엔드 테스트 21개 통과. 프런트엔드 빌드 성공. 실행 중인 검색이 없는 것을 확인하고 서버를 재시작했으며, HTTP 200과 최신 번들 제공을 확인했다.
- X·Y, 초록만의 X, 기준일 이후 문헌에 따른 전환을 회귀 테스트로 확인했다.
- 시간 예약 복원, 첫 단계 실패 후 후속 진행 가능 상태, 후보 합집합 유지, 여러 구성에 걸친 후보 선택을 확인했다.
- UI는 X 미확인과 문헌 부재를 구분하고 실제 질의 및 실행 단계를 표시한다.
- 네 단어 절단은 저비용 휴리스틱으로, 복합 용어가 잘릴 수 있다. 다양한 청구항의 반복 평가가 필요하다. 원래 구성별 쿼리와 전체 청구항을 후속 경로에 유지한다.
- 웹 순위 의존, KR 영문 초록 커버리지, 미구현 인용·family 확장, LLM 판정 변동은 남아 있다. 한 X 발견 후 종료하므로 모든 관련 문헌을 수집하는 모드는 아니다.
