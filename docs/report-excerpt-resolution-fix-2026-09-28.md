# 발췌 선택과 차이 해소 근거 연결 개선

## 원인과 변경

대상 실행은 `eb58562a-1361-415b-a03a-de3fbe77ad4c`다. 문헌 5개의 전체 추출 텍스트가 전달됐지만 모델이 연속되지 않는 구절을 합치거나 페이지를 잘못 작성했다. 기존 출력기는 잘못된 발췌를 숨기면서 그 근거에 의존하는 보완 설명을 유지했고, 차이 해소 검토에 필요한 보완 문헌의 근거 연결도 검사하지 않았다.

- 전체 문헌·로컬 검색 모두 원문의 선택 번호를 제공한다. 모델이 원문을 다시 쓰거나 문자 위치를 계산하지 않고 번호를 선택하면 프로그램이 해당 구간 전체와 위치를 복원한다. 원문 전체와 기존 검색 범위는 보존하고 색인 크기도 기존 입력 예산에 포함한다.
- 차이 해소 검토에 보완할 차이·근거 ID·설명·잔존 차이·판단 상태를 받는다. 해당 절 안에 외국어 번역, 원문 발췌와 위치, 보완 설명을 차례대로 출력한다. 한글 문헌에는 번역을 요구하지 않는다.
- 연결 누락·발췌 검증 실패·번역 누락은 해당 판단을 확인 필요로 표시한다. 검증되지 않은 설명과 종합 요약의 보완 결론을 확정된 결과처럼 표시하지 않는다.
- 이전 직접 발췌의 페이지 오기는 전달된 원문에서 일치 페이지가 하나뿐인 경우만 정정한다. 근사 일치·역번역·생략 구절 연결은 하지 않는다.

## 실제 저장 응답의 재검증

새 모델 호출 없이 원 응답을 재조립했다. E3는 동일한 문장이 있는 14쪽, E4는 9쪽으로 위치가 정정됐다. 검증된 발췌는 4개에서 6개로 늘었다. E2·E8의 합성·변형 발췌는 계속 제외된다. 이전 자유서술 차이 해소 검토는 근거 ID 연결이 없으므로 6개 구성 모두 확인 필요로 표시됐다. 새 근거나 새로운 기술적 판단을 생성한 결과가 아니다.

점검용 출력은 `artifacts/report-evidence-replay-20260928/validation-preview.md`, 상태 기록은 같은 폴더의 `validation-summary.json`에 있다. 기존 저장 보고서는 덮어쓰지 않았다.

## 적용 범위

새로 생성하는 구조화 보고서에 적용된다. 기존 응답 형식도 읽지만 근거 연결을 추정하지 않는다. 추가 분석 모델 호출은 도입하지 않았다. 선택한 구간의 기술적 적합성과 번역 정확성은 모델이 판단하며, 문자 검증 통과만으로 결합 타당성이 입증되지는 않는다.

## 검증과 실행 앱 반영

- 발췌 선택·보고서 조립·입력 예산·검색 전달·보고서 무결성 테스트 272개 통과. 업로드부터 실행·이력까지 전달 통합 테스트와 검색 API 테스트 22개도 통과했다. 테스트의 제거된 프롬프트 API 의존은 현재 내장 지침 방식으로 정리했다.
- 잘못된 문헌·없는 구간·구간 범위 변조·빈 검색 패키지·페이지 오기·문장 합성·한글 문헌·번역 누락·보완 근거 누락·이전 자유서술 응답을 검증했다. 추가 모델 호출 없이 결과가 저장되는 실행 경로도 확인했다.
- 실제 자료 5개의 선택 색인은 983개 구간, 63,381자로 측정됐다. 원 입력 약 36만 자 외에 이 색인이 추가되며 기존 입력 한도 검사에 포함된다.
- 실행·대기 중인 작업이 없는 것을 확인한 뒤 이 작업공간의 앱 서버(8765·8766·8767)를 재시작했다. 세 주소 모두 정상 응답하고 이전 이력이 유지됨을 확인했다.
- 실제 LLM으로 새 보고서를 생성해 품질을 비교하는 호출은 수행하지 않았다. 기존 저장 응답의 재검증과 자동 테스트 결과다.
