PRISM — Windows x64 소스 실행 배포본

처음 사용
1. ZIP 전체를 쓰기 가능한 폴더에 압축 해제합니다. ZIP 안에서 실행하지 마세요.
2. 처음설치.cmd를 더블클릭하고 사용할 CLI를 선택합니다.
   Python 3.11/3.12 x64가 없으면 Python 3.11을 설치합니다.
   PRISM 폴더의 backend\.venv에 Python 라이브러리를 설치합니다.
   Claude Code는 네이티브 방식으로, Codex는 필요한 경우 Node.js LTS와 npm으로 설치합니다.
   이미 있는 CLI는 --version으로 확인하며 자동으로 교체하지 않습니다.
   agy는 기존 설치만 확인합니다. 별도의 Google Gemini CLI로 대체할 수 없습니다.
   '나중에 설치'를 선택하면 AI 분석 전에 CLI를 별도로 설치해야 합니다.
3. PRISM실행.cmd를 더블클릭합니다. 브라우저가 자동으로 열립니다.
4. Settings → AI 실행 도구 상태에서 로그인하고 사용할 도구를 지정합니다.
   검색에 필요한 EPO·KIPRIS·OpenAlex 자격증명은 별도로 설정합니다.

이후 실행과 종료
- PRISM실행.cmd만 실행하면 됩니다. 매번 설치하지 않습니다.
- 실행 콘솔을 유지하세요. 종료는 콘솔에서 Ctrl+C입니다.
- 브라우저 탭만 닫으면 서버는 종료되지 않습니다.
- 기본 주소는 http://127.0.0.1:8765이며, 사용 중이면 다른 포트를 선택합니다.

설치 환경
- Windows 10/11 x64, 인터넷 연결, 설치 가능한 사용자 환경이 필요합니다.
- 자동 설치는 winget을 사용합니다. 없는 경우 표시되는 공식 사이트에서 설치 후 재시도하세요.
- Node.js 설치 시 Windows의 관리자 승인 창이 나올 수 있습니다.
- 사내 정책으로 설치/스크립트 실행이 차단되면 관리자에게 문의하세요.
- 화면은 미리 빌드되어 있습니다. 프론트엔드를 위해 Node.js를 설치할 필요는 없습니다.
- Python은 3.11/3.12 x64를 사용합니다. 3.13 이상은 이 배포의 지원 범위가 아닙니다.
- 실패하면 오류를 확인하고 처음설치.cmd를 다시 실행하세요. 실패한 단계를 성공으로 처리하지 않습니다.
- 폴더 이동으로 가상환경이 깨진 경우 backend\.venv 폴더 이름을 변경한 후 다시 설치하세요.

데이터와 업데이트
- 설정·이력: %LOCALAPPDATA%\PRISM (PRISM_DATA_DIR로 변경 가능)
- 편집한 프롬프트: PRISM 폴더의 prompt (PRISM_PROMPT_DIR로 변경 가능)
- 새 버전은 별도 폴더에 풀고 처음설치.cmd를 실행하세요. 편집한 프롬프트는 백업 후 옮기세요.
- 설치 시 사용자 설정·이력·CLI 로그인 정보를 배포본으로 덮어쓰지 않습니다.
- 프로그램 폴더를 삭제해도 시스템에 설치한 Python·Node.js·CLI와 사용자 데이터는 남습니다.
- AI 작업에는 각 서비스의 로그인과 사용 가능한 계정이 필요합니다.
- 선택한 AI 서비스로 입력 자료가 전송됩니다. 선택 기능인 의미 검색 모델은 포함하지 않습니다.
