PRISM 2.0.5 — Windows 설치 / 업데이트 / 제거

[처음 설치]
1. PRISM-2.0.5-Setup-x64.exe를 더블클릭합니다.
   ZIP으로 받았다면 압축을 풀고 안의 같은 EXE를 실행합니다.
2. 설치와 실행 환경 준비가 끝날 때까지 기다립니다.
3. 바탕 화면 또는 시작 메뉴의 PRISM을 실행합니다.
4. PRISM Settings에서 사용할 AI 계정에 로그인합니다.

설치 위치는 기본적으로 %LOCALAPPDATA%\Programs\PRISM입니다.
Python, 라이브러리, Node.js, Claude Code, Codex, agy가 필요하면 설치합니다.
이미 있는 도구는 재사용합니다. 인터넷 연결이 필요합니다.
WinGet이 없으면 Microsoft 공식 배포본을 준비합니다.
조직 정책으로 차단되면 IT 관리자에게 문의하세요.

[새 버전으로 업데이트]
Git이나 pull을 몰라도 됩니다. 새 버전의 Setup.exe를 받아 실행하세요.
실행 중인 PRISM 콘솔에서 Ctrl+C로 종료한 뒤 설치해야 합니다.
브라우저만 닫으면 PRISM 서버는 계속 실행됩니다.
설치기는 기존 설치 위치를 찾아 업데이트합니다. 먼저 제거하지 마세요.
히스토리·설정·첨부파일·편집 프롬프트는 유지됩니다.
Python 가상환경은 재사용하며 필요한 라이브러리를 갱신합니다.
자동 새 버전 확인/다운로드 기능은 없습니다.
환경 준비에 실패하면 설치 폴더의 설치.cmd로 다시 시도합니다.
오류 로그는 설치 폴더의 app\.setup에 있습니다.

[이전 ZIP 사용자가 처음 EXE로 전환할 때]
기존 히스토리와 설정(%LOCALAPPDATA%\PRISM)은 자동으로 이어집니다.
프롬프트를 편집했다면 설치 중 이전 ZIP의 app 폴더를 선택하세요.
이후에는 새 바탕 화면/시작 메뉴 바로가기를 사용하세요.
이전 ZIP 폴더는 새 설치본의 정상 실행과 프롬프트를 확인한 뒤 직접 지워도 됩니다.
이전 ZIP에서 설치했던 CLI는 설치 소유권 기록이 없어 새 설치기 소유로 처리하지 않습니다.

[제거]
Windows 설정 → 앱 → PRISM, 시작 메뉴의 PRISM 제거, 또는 설치 폴더의 제거.cmd를 실행합니다.
설치 폴더의 unins000.exe가 실제 제거 프로그램입니다.
기본 삭제: 프로그램, 가상환경, 편집 프롬프트, %LOCALAPPDATA%\PRISM의
히스토리·설정·첨부파일·실행 기록·캐시 및 새 설치기가 설치했다고 기록한 CLI.
agy에 등록한 PRISM 검색 서버와 그 권한도 정리합니다.

제거 화면에서 다음 항목을 추가로 선택할 수 있습니다.
- 공유 CLI 기록: .codex, .claude, .claude.json, .gemini\antigravity-cli,
  .gemini\config의 로컬 설정·계정 파일·세션을 삭제합니다.
  다른 프로젝트, Codex 앱, Gemini/Antigravity의 공유 설정에도 영향이 있습니다.
  해당 앱과 CLI를 모두 닫고, 필요한 기록을 백업한 후 선택하세요.
- 기존 CLI: 이전 ZIP 설치 등 설치 주체를 알 수 없는 CLI도 제거합니다.
  npm 전역 Codex, WinGet Claude Code, 기본 위치 agy만 지원합니다.
- Python·Node.js: PRISM 설치기가 새로 설치했다고 기록한 런타임도 제거합니다.
  다른 프로그램에서도 사용 중이라면 이 항목은 선택하지 마세요.

삭제는 되돌릴 수 없습니다. 실패 시 오류를 표시하고 제거를 중단하므로 해결 후 재시도하세요.
클라우드에 저장된 대화, 서비스 계정, OS 자격증명 저장소, 따로 내보낸 파일,
이전에 풀어둔 ZIP 폴더, 다른 설치 방식/경로의 도구까지 삭제하는 기능은 아닙니다.
PRISM_DATA_DIR, PRISM_PROMPT_DIR, CODEX_HOME 등 사용자 지정 경로는 직접 정리해야 합니다.
기본 데이터/공유 설정 경로가 다른 곳으로 연결된 링크이면 자동 삭제를 중단합니다.
다른 앱도 사용하는 WinGet과 시스템 패키지 캐시는 유지합니다.

지원 환경: Windows 10/11 x64, Python 3.11/3.12 x64.
