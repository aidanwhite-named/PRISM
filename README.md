# PRISM

**Patent Retrieval & Invention Similarity Mapping**

특허의 기술적 구성을 나누고, 관련 문헌의 근거와 연결하는 AI 특허 분석 워크스페이스입니다.

## 핵심 아이디어

하나의 발명을 청구항의 구성별로 살펴보고, 특허·논문에서 대응하는 기술과 차이점을 찾습니다. **문헌 검색 → 원문 확보 → 구성대비 → 부족한 근거 보완**을 한 작업 흐름으로 연결해, 어떤 구성에 어떤 문헌이 대응하는지 확인할 수 있습니다.

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| 유사문헌 검색 | 청구항과 기술 설명을 바탕으로 특허·논문을 탐색하고, 원문과 인용 관계를 확인합니다. |
| 구성대비 분석 | 첨부 PDF나 검색에서 선택한 문헌을 청구항과 비교해 구성별 대응 근거·유사도·차이점을 보고서로 정리합니다. |
| 보완 검색 | 대응 근거가 부족한 구성을 추가로 검색하고, 종속항의 추가 특징을 따로 탐색합니다. |
| 보고서 활용 | 보고서에 관해 질문하고, 후속 분석과 결과 내보내기를 진행합니다. |
| 정답 라이브러리 | 검토한 보고서와 근거를 사례로 보관하고, 분석에 활용할 예시와 작성 스타일을 관리합니다. |
| 실행 기록 | 입력 자료, 검토 범위, 출처와 결과를 PC에 저장해 이전 작업을 다시 확인합니다. |

AI 실행 도구는 **Claude Code, Codex CLI, agy**를 지원합니다. 검색 서비스는 **EPO, KIPRIS, OpenAlex** 등을 연동할 수 있습니다.

## 시작하기

1. [최신 릴리즈](https://github.com/aidanwhite-named/PRISM/releases/latest)에서 `PRISM-버전-Setup-x64.exe`를 설치합니다.
2. **PRISM**을 실행하고, **환경 설정**에서 사용할 AI 실행 도구에 로그인합니다.
3. **유사문헌 검색**에 청구항을 입력하거나, **구성대비 분석**에 비교할 문서를 첨부합니다.
4. 결과와 근거를 확인하고, 필요한 구성의 검색이나 분석을 이어갑니다.

설치·업데이트·제거 안내는 [사용안내.txt](사용안내.txt)를 참고하세요.

## 실행 환경

- Windows 10/11 x64에서 브라우저로 사용하는 로컬 웹 애플리케이션입니다.
- 첨부 분석은 텍스트 기반 PDF를 지원합니다.
- AI 실행과 외부 문헌 검색에는 인터넷 연결 및 해당 서비스 계정이 필요합니다.
- 실행 이력과 설정은 `%LOCALAPPDATA%\PRISM`에 저장합니다. `PRISM_DATA_DIR`로 경로를 지정할 수 있습니다.

소스에서 실행하려면 Python 3.11/3.12 x64와 Node.js LTS를 준비한 뒤 아래 명령을 사용합니다.

```powershell
.\start-prism.ps1 -Setup  # 최초 설정 및 실행
.\start-prism.ps1         # 이후 실행
```
